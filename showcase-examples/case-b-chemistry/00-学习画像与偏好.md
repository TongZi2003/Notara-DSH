# 学习画像与偏好

## 我是谁与当前水平
- **学习者身份**：高三理科生，正在进行高考化学专题一轮/二轮复习。
- **学习目的与水平梯度**：**学科应试通关 × 第二梯度 · 独立破局期（1 $\rightarrow$ N）**。
- **当前认知底座**：
  - 已掌握元素化合物基础反应（铁、铝、铜、锰的常见价态与氧化物/氢氧化物性质）、氧化还原反应配平、水的离子积常数 $K_w = c(\text{H}^+)\cdot c(\text{OH}^-)$、$\text{pH} = -\lg c(\text{H}^+)$ 以及难溶电解质溶度积常数 $K_{sp}$ 的基本表达式。
  - 处于典型的“看答案解析觉得每一步都顺理成章（流畅性错觉），但合上答案独立做题就卡在第一步触发信号与定量算账”阶段。

## 教学偏好
- **有效讲法**：
  - 讲概念与方法时，直接点明“题干里的什么信号触发这一步操作”以及“从已知浓度和 $K_{sp}$ 到目标 $\text{pH}$ 的完整代数变形桥梁”。
  - 借助可视化流程图（`flow`）、操作排序（`order`）与判据辨析（普通辨析题）把长工业流程的主干拆清，将关键试剂选择与 $\text{pH}$ 临界值留白让我动手推演。
- **易烦雷区**：
  - 反感空洞的鸡汤说教与故弄玄虚的套话；拒绝机械背诵口诀而不讲清平衡移动与定量数据支撑。

## 学习习惯与常见卡点
- **高频思维与审题卡点**：
  1. **试剂选择盲区**：面对“加入氧化剂”或“加入试剂 X 调节 $\text{pH}$”，不清楚如何在实现氧化/消耗 $\text{H}^+$ 的同时满足“不引入新杂质”的约束。
  2. **$\text{pH}$ 区间上下限逻辑模糊**：不清楚为什么调节 $\text{pH}$ 必须控制在某两个具体数值之间（左边界保杂质除尽、右边界保主离子不沉），以及为什么必须先把 $\text{Fe}^{2+}$ 氧化成 $\text{Fe}^{3+}$ 才能调 $\text{pH}$。
  3. **$K_{sp}$ 定量换算断层**：从 $K_{sp}[\text{M(OH)}_n] = c(\text{M}^{n+})\cdot c^n(\text{OH}^-)$ 开 $n$ 次方求 $c(\text{OH}^-)$，再经 $K_w$ 或 $\text{pOH}$ 换算为 $\text{pH}$ 时容易算错幂次或搞反不等号方向。
  4. **题干限定词漏检**：审题时常忽略“过量稀硫酸”、“趁热过滤”等修饰词对后续步骤试剂消耗与产物收率的连锁影响。

## 积累
- **工业流程除杂双约束**：选择氧化剂或调 $\text{pH}$ 试剂时，同时核查“能否完成目标化学转化（氧化 $\text{Fe}^{2+}$ 或消耗 $\text{H}^+$）”与“反应产物是否为水、气体或主金属离子（不引入新杂质）”。
- **调 pH 范围两头堵原则**：调节 $\text{pH}$ 除杂的下限由需要除去的所有杂质离子全部完全沉淀（$c \le 1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$）的最大 $\text{pH}$ 决定，上限由主金属离子开始形成沉淀的临界 $\text{pH}$ 决定。
