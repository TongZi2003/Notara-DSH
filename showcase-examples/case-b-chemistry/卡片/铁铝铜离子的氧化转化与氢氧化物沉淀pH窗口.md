# 铁铝铜离子的氧化转化与氢氧化物沉淀pH窗口

## 内容

在以硫酸盐或盐酸盐为主的工业酸浸液中，常见金属阳离子（按初始浓度 $c_0 = 0.10\text{ mol}\cdot\text{L}^{-1}$，完全沉淀残留浓度 $c = 1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$，室温 $25^\circ\text{C}$ 计）的溶度积常数 $K_{sp}$ 及对应的沉淀 $\text{pH}$ 窗口如下表所示：

| 阳离子 | 对应氢氧化物 | 室温 $K_{sp}$ 典型值 | 开始沉淀 $\text{pH}$ ($c_0 = 0.10\text{ mol/L}$) | 完全沉淀 $\text{pH}$ ($c \le 10^{-5}\text{ mol/L}$) |
| :--- | :---: | :---: | :---: | :---: |
| $\text{Fe}^{3+}$ | $\text{Fe(OH)}_3$ | $8.0 \times 10^{-38}$ | $1.97$ | $3.30$ |
| $\text{Al}^{3+}$ | $\text{Al(OH)}_3$ | $1.0 \times 10^{-32}$ | $3.67$ | $5.00$ |
| $\text{Cu}^{2+}$ | $\text{Cu(OH)}_2$ | $2.2 \times 10^{-20}$ | $4.67$ | $6.67$ |
| $\text{Fe}^{2+}$ | $\text{Fe(OH)}_2$ | $1.0 \times 10^{-15}$ | $7.00$ | $9.00$ |
| $\text{Mn}^{2+}$ | $\text{Mn(OH)}_2$ | $1.0 \times 10^{-13}$ | $8.00$ | $10.00$ |

- **氧化转化核心方程**：
  - 使用双氧水（$\text{H}_2\text{O}_2$）氧化：
    $$2\text{Fe}^{2+} + \text{H}_2\text{O}_2 + 2\text{H}^+ = 2\text{Fe}^{3+} + 2\text{H}_2\text{O}$$
  - 在锰盐制备体系中使用二氧化锰（$\text{MnO}_2$）氧化：
    $$2\text{Fe}^{2+} + \text{MnO}_2 + 4\text{H}^+ = 2\text{Fe}^{3+} + \text{Mn}^{2+} + 2\text{H}_2\text{O}$$

## 参考理解

### 1. 引入动机：为何直接调 $\text{pH}$ 无法除去浸出液中的 $\text{Fe}^{2+}$
矿石（如菱锰矿、黄铁矿烧渣、废旧电池正负极料）在酸浸过程中，由于还原性伴生矿物或金属单质的存在，铁元素往往大量以二价亚铁离子 $\text{Fe}^{2+}$ 的形式进入溶液。若试图不加氧化剂、直接向溶液中加碱调高 $\text{pH}$ 除去 $\text{Fe}^{2+}$，依据 [[卡片/溶度积Ksp与离子完全沉淀的pH定量判据]] 的换算方法，由 $K_{sp}[\text{Fe(OH)}_2] = 1.0 \times 10^{-15}$ 可算得：$\text{Fe}^{2+}$ 要到 $\text{pH} = 7.00$ 才开始沉淀，直至 $\text{pH} = 9.00$ 才能完全沉淀。

然而观察上表可知，常见主金属离子如 $\text{Cu}^{2+}$ 在 $\text{pH} = 4.67$ 即开始沉淀（$\text{pH} = 6.67$ 已全部沉淀），$\text{Mn}^{2+}$ 在 $\text{pH} = 8.00$ 即开始沉淀。这意味着当溶液 $\text{pH}$ 升至 $9.00$ 以除尽 $\text{Fe}^{2+}$ 时，溶液中的主金属离子 $\text{Cu}^{2+}$ 或 $\text{Mn}^{2+}$ 早已大量甚至全部转化为氢氧化物沉淀进入滤渣，导致提纯彻底失败。

### 2. 氧化转化的机制：将高 $\text{pH}$ 沉淀离子平移至低 $\text{pH}$ 窗口
对比三价铁与二价铁的溶度积常数，$K_{sp}[\text{Fe(OH)}_3] = 8.0 \times 10^{-38}$ 比 $K_{sp}[\text{Fe(OH)}_2] = 1.0 \times 10^{-15}$ 小了超过 $22$ 个数量级。当 $c(\text{Fe}^{3+}) = 1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$ 时：
$$c(\text{OH}^-) = \sqrt[3]{\frac{8.0 \times 10^{-38}}{1.0 \times 10^{-5}}} = \sqrt[3]{8.0 \times 10^{-33}} = 2.0 \times 10^{-11}\text{ mol}\cdot\text{L}^{-1}$$
对应 $\text{pOH} = 11 - \lg 2 = 10.70$，完全沉淀所需 $\text{pH} = 14 - 10.70 = 3.30$。
通过加入 $\text{H}_2\text{O}_2$ 或 $\text{MnO}_2$ 将 $\text{Fe}^{2+}$ 全部氧化为 $\text{Fe}^{3+}$，相当于把铁杂质完全沉淀的阈值从 $\text{pH} = 9.00$ 大幅左移至 $\text{pH} = 3.30$，从而在 $\text{Cu}^{2+}$（开始沉淀 $\text{pH} = 4.67$）或 $\text{Mn}^{2+}$（开始沉淀 $\text{pH} = 8.00$）尚未沉淀的安全区内将铁元素彻底分离。

### 3. 各离子沉淀窗口的数轴分布与两性边界
将上述五种离子的沉淀区间投影在同一条 $\text{pH}$ 数轴上，可以清晰识别工业除杂的三条核心规律：
- **铁铝共沉区（$\text{pH} \ge 5.00$）**：$\text{Fe}^{3+}$ 在 $\text{pH} = 3.30$ 完全沉淀，$\text{Al}^{3+}$ 在 $\text{pH} = 5.00$ 完全沉淀。对于制备 $\text{MnSO}_4$ 的流程（$\text{Mn}^{2+}$ 开始沉淀 $\text{pH} = 8.00$），控制 $5.00 \le \text{pH} < 8.00$ 即可一次性将 $\text{Fe}^{3+}$ 与 $\text{Al}^{3+}$ 同时转化为 $\text{Fe(OH)}_3$、$\text{Al(OH)}_3$ 滤渣除去（详见 [[卡片/例题-硫酸锰浸出液氧化除铁铝的pH范围计算与试剂选择]]）。
- **$\text{Al(OH)}_3$ 的两性溶解上限**：氢氧化铝属于两性氢氧化物（即既能与酸反应生成 $\text{Al}^{3+}$，又能与强碱反应生成四羟基合铝酸根 $[\text{Al(OH)}_4]^-$ 的氢氧化物）。当调节 $\text{pH}$ 除铝时，若 $\text{pH}$ 过高（通常 $\text{pH} > 10$），已生成的 $\text{Al(OH)}_3$ 沉淀会发生反应 $\text{Al(OH)}_3 + \text{OH}^- \rightleftharpoons [\text{Al(OH)}_4]^-$ 重新溶解回到滤液中，导致除铝失效。
- **铜铝窗口重叠边界**：对比表中 $\text{Al}^{3+}$（完全沉淀 $\text{pH} = 5.00$）与 $0.10\text{ mol}\cdot\text{L}^{-1}$ 的 $\text{Cu}^{2+}$（开始沉淀 $\text{pH} = 4.67$）可以发现，当 $\text{pH}$ 升至 $5.00$ 使 $\text{Al}^{3+}$ 完全沉淀时，$\text{Cu}^{2+}$ 已经开始析出。因此含铜废料若仅含 $\text{Fe}^{3+}$ 杂质，可在 $3.30 \le \text{pH} < 4.67$ 下一步调 $\text{pH}$ 除铁；若同时含较高浓度的 $\text{Al}^{3+}$ 与 $\text{Cu}^{2+}$，则需要结合其他分离手段（详见 [[卡片/工艺流程调pH除杂与不引入新杂质试剂选法]]）。

### 下次探讨
1. **双氧水用量的实际偏差**：在步骤②用 $\text{H}_2\text{O}_2$ 氧化 $\text{Fe}^{2+}$ 时，工厂实际消耗的 $\text{H}_2\text{O}_2$ 物质的量往往明显大于按 $2\text{Fe}^{2+} + \text{H}_2\text{O}_2 + 2\text{H}^+ = 2\text{Fe}^{3+} + 2\text{H}_2\text{O}$ 算出的理论化学计量值。结合反应生成的产物性质，有哪些因素导致了 $\text{H}_2\text{O}_2$ 的额外消耗？
2. **次氯酸盐或氯气作氧化剂的适用边界**：若在制备高纯硫酸锰（$\text{MnSO}_4$）的流程中，将氧化剂 $\text{MnO}_2$ 替换为 $\text{Cl}_2$ 或 $\text{NaClO}$ 溶液来氧化 $\text{Fe}^{2+}$，会对后续结晶提纯 $\text{MnSO}_4$ 带来什么新问题？
