# 溶度积Ksp与离子完全沉淀的pH定量判据

## 内容

在工业流程的溶液除杂工序中，常通过调节溶液的 $\text{pH}$ 控制氢氧根离子浓度 $c(\text{OH}^-)$，使杂质金属离子转化为难溶氢氧化物沉淀，同时保持主金属离子留在溶液中。

1. **溶度积常数（$K_{sp}$）表达式**：
   对于通式为 $\text{M(OH)}_n(\text{s})$ 的难溶金属氢氧化物，在水溶液中存在如下沉淀溶解平衡：
   $$\text{M(OH)}_n(\text{s}) \rightleftharpoons \text{M}^{n+}(\text{aq}) + n\text{OH}^-(\text{aq})$$
   在一定温度下，当沉淀溶解达到平衡状态（即饱和溶液）时，溶液中金属阳离子浓度与氢氧根离子浓度幂次的乘积为一个常数，称为溶度积常数 $K_{sp}$：
   $$K_{sp}[\text{M(OH)}_n] = c(\text{M}^{n+}) \cdot c^n(\text{OH}^-)$$

2. **完全沉淀与开始沉淀的定量判据（室温 $25^\circ\text{C}$，$K_w = c(\text{H}^+)\cdot c(\text{OH}^-) = 1.0 \times 10^{-14}$）**：
   - **沉淀完全判据**：定量分析与工业除杂中普遍约定，当溶液中某离子的残留浓度降至 $c(\text{M}^{n+}) \le 1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$ 时，即可认为该离子已**完全沉淀**。
   - **开始沉淀判据**：当任意時刻溶液中的离子积 $Q_c = c(\text{M}^{n+}) \cdot c^n(\text{OH}^-)$ 恰好增大到等于 $K_{sp}[\text{M(OH)}_n]$ 时，难溶氢氧化物处于开始析出沉淀的临界状态；若要保证初始浓度为 $c_0$ 的主金属离子不沉淀损失，必须满足 $Q_c < K_{sp}[\text{M(OH)}_n]$。

## 参考理解

### 1. 引入动机：为何定性除杂必须升级为定量区间计算
在基础无机化学中，除去酸性溶液中的 $\text{Fe}^{3+}$ 或 $\text{Al}^{3+}$ 通常描述为“加碱生成 $\text{Fe(OH)}_3$、$\text{Al(OH)}_3$ 沉淀”。然而在真实工业浸出液中，杂质离子（如 $\text{Fe}^{3+}$、$\text{Al}^{3+}$）与高浓度的目标主金属离子（如 $0.10\text{ mol}\cdot\text{L}^{-1}$ 的 $\text{Mn}^{2+}$ 或 $\text{Cu}^{2+}$）共存于同一溶液体系。若加入碱性物质过少、溶液 $\text{pH}$ 偏低，则 $\text{OH}^-$ 浓度不足，杂质离子沉淀不彻底，影响产品纯度；若溶液 $\text{pH}$ 偏高，则 $\text{OH}^-$ 浓度过大，主金属离子也会达到其氢氧化物的溶度积而生成沉淀，造成主产物收率下降。因此，必须借助溶度积常数 $K_{sp}$ 进行定量推算，找出既能把杂质除尽、又不会让主金属离子析出的精确 $\text{pH}$ 窗口。

### 2. 定义拆解与关键限定词
运用上述定量判据时，需逐一核对三个核心限定条件：
- **残留浓度阈值 $1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$ 的物理意义**：难溶电解质的溶解平衡永远存在，溶液中不可能出现 $c(\text{M}^{n+}) = 0$ 的绝对零浓度状态。化学上规定 $1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$ 为定量完全沉淀的边界，计算“杂质恰好完全沉淀的最小 $\text{pH}$”时，直接将 $c(\text{杂质}^{n+}) = 1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$ 代入 $K_{sp}$ 表达式（若极少数题目专门声明了 $1.0 \times 10^{-6}\text{ mol}\cdot\text{L}^{-1}$，则以题干声明为准）。
- **主金属离子开始沉淀使用的是初始浓度 $c_0$**：计算“主金属离子开始沉淀的临界 $\text{pH}$”时，主金属离子尚未因沉淀而发生浓度下降，因此代入 $K_{sp}$ 表达式的阳离子浓度是题干给定的浸出液实际浓度 $c_0$（例如 $0.10\text{ mol}\cdot\text{L}^{-1}$ 或 $1.0\text{ mol}\cdot\text{L}^{-1}$），切勿将其与 $1.0 \times 10^{-5}\text{ mol}\cdot\text{L}^{-1}$ 混淆。
- **化学计量数 $n$ 与幂次的严格对应**：在 $\text{M(OH)}_n(\text{s}) \rightleftharpoons \text{M}^{n+}(\text{aq}) + n\text{OH}^-(\text{aq})$ 中，$1\text{ mol}$ 阳离子结合 $n\text{ mol }\text{OH}^-$。因此三价离子（如 $\text{Fe}^{3+}$、$\text{Al}^{3+}$，$n=3$）的表达式中为 $c^3(\text{OH}^-)$，求解 $c(\text{OH}^-)$ 时需开立方；二价离子（如 $\text{Fe}^{2+}$、$\text{Cu}^{2+}$、$\text{Mn}^{2+}$，$n=2$）的表达式中为 $c^2(\text{OH}^-)$，求解 $c(\text{OH}^-)$ 时需开平方。

### 3. 从 $K_{sp}$ 到临界 $\text{pH}$ 的四步标准推导链
由于 $K_{sp}$ 表达式直接给出的是 $c(\text{OH}^-)$，而题目要求的是 $\text{pH} = -\lg c(\text{H}^+)$，中间可以引入氢氧根浓度负对数 $\text{pOH} = -\lg c(\text{OH}^-)$ 作为换算桥梁（室温下由 $K_w = c(\text{H}^+)\cdot c(\text{OH}^-) = 1.0 \times 10^{-14}$ 两边取负对数，直接得到 $\text{pH} + \text{pOH} = 14$）：
1. **列平衡式求 $c^n(\text{OH}^-)$**：由 $K_{sp}[\text{M(OH)}_n] = c(\text{M}^{n+}) \cdot c^n(\text{OH}^-)$，变形得：
   $$c^n(\text{OH}^-) = \frac{K_{sp}[\text{M(OH)}_n]}{c(\text{M}^{n+})}$$
2. **调整指数并开 $n$ 次方求 $c(\text{OH}^-)$**：先将右侧科学计数法的指数调整为 $n$ 的整数倍，再开 $n$ 次方：
   $$c(\text{OH}^-) = \sqrt[n]{\frac{K_{sp}[\text{M(OH)}_n]}{c(\text{M}^{n+})}}$$
3. **取负对数求 $\text{pOH}$**：
   $$\text{pOH} = -\lg c(\text{OH}^-)$$
4. **换算为室温下的临界 $\text{pH}$**：
   $$\text{pH} = 14 - \text{pOH} = 14 + \lg c(\text{OH}^-)$$

### 4. “两头堵”区间合并法则与上下游联系
当浸出液中含有多种需要除去的杂质离子（如同时含 $\text{Fe}^{3+}$ 和 $\text{Al}^{3+}$）时：
- **下限（左边界）取大（$\max$）**：只有当 $\text{pH}$ 达到所有杂质离子完全沉淀所需 $\text{pH}$ 中的最大值时，最难沉淀的那种杂质才能除尽；
- **上限（右边界）取小（$\min$）**：$\text{pH}$ 必须严格小于主金属离子开始沉淀的临界 $\text{pH}$：
  $$\max\{\text{各杂质完全沉淀的 pH}\} \le \text{pH} < \min\{\text{主金属离子开始沉淀的 pH}\}$$
这一法则直接解释了不同金属离子的分离窗口差异（详见 [[卡片/铁铝铜离子的氧化转化与氢氧化物沉淀pH窗口]]），并为工业流程的除杂控制提供了定量依据（详见 [[卡片/工艺流程调pH除杂与不引入新杂质试剂选法]] 与实战例题 [[卡片/例题-硫酸锰浸出液氧化除铁铝的pH范围计算与试剂选择]]）。

### 下次探讨
1. **初始浓度平移效应**：对于二价主金属离子 $\text{Mn}^{2+}$（$n=2$），若浸出液经稀释后 $c(\text{Mn}^{2+})$ 从 $0.10\text{ mol}\cdot\text{L}^{-1}$ 变为 $0.0010\text{ mol}\cdot\text{L}^{-1}$（减小 $100$ 倍），其开始沉淀的上限 $\text{pH}$ 会向哪个方向移动多少个单位？
2. **温度改变时的双参数联动**：工业上“趁热过滤”常在 $80^\circ\text{C}$ 下进行，此时水的离子积 $K_w$ 增大至约 $2.5 \times 10^{-13}$（即 $\text{pH} + \text{pOH} \approx 12.6$），且难溶氢氧化物的 $K_{sp}$ 也随温度变化。若直接套用 $\text{pH} = 14 - \text{pOH}$ 会产生怎样的系统偏差？
