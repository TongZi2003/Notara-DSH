# 工艺流程调pH除杂与不引入新杂质试剂选法

## 内容

在无机化工生产流程题中，从矿石酸浸液到纯净目标盐溶液的标准除杂模块通常遵循如下主干工序：

$$\text{矿石酸浸液}(\text{含主离子 }\text{M}^{2+}\text{ 及 }\text{H}^+、\text{Fe}^{2+}、\text{Fe}^{3+}、\text{Al}^{3+}) \xrightarrow{\text{① 加氧化剂}} \text{高价态混合液} \xrightarrow{\text{② 加调 pH 试剂 X}} \text{悬浊液} \xrightarrow{\text{③ 过滤（常伴趁热）}} \begin{cases} \text{滤渣：}\text{Fe(OH)}_3、\text{Al(OH)}_3\text{ 及过量固体 X} \\ \text{滤液：纯净 }\text{M}^{2+}\text{ 盐溶液} \end{cases}$$

本卡片汇总该模块在审题识别、氧化剂与调 $\text{pH}$ 试剂选择、标准答题表述、高频漏检限定词及方法失效边界上的通用法则。

## 参考理解

### 1. 触发信号与核心动机
当工艺流程图中出现以下三类特征信号之一时，即可判定该工序属于“氧化—调 $\text{pH}$ 水解沉淀除杂”模块：
- 流程箭头旁标注“加 $\text{H}_2\text{O}_2$ / $\text{MnO}_2$ / 通空气”、“加 $\text{MO}$ / $\text{MCO}_3$ 调节 $\text{pH}$ 至 $a \sim b$”；
- 滤渣成分提示为“黄铵铁矾 / 红褐色沉淀 $\text{Fe(OH)}_3$ / 白色沉淀 $\text{Al(OH)}_3$”；
- 题干下方附带了各金属氢氧化物的溶度积常数 $K_{sp}$ 表或“开始沉淀—完全沉淀 $\text{pH}$”对照表。

### 2. “自变量—中间过程—因变量”因果链与标准答题话术
解答“加入某试剂的目的”或“调节 $\text{pH}$ 的原理”时，严格按以下三步因果链组织语言：
1. **氧化步（自变量：加入绿色氧化剂）**：
   - **中间过程**：在酸性条件下将低价态 $\text{Fe}^{2+}$ 完全氧化为高价态 $\text{Fe}^{3+}$；
   - **因变量（目的）**：因 $\text{Fe}^{3+}$ 完全沉淀所需 $\text{pH}$（约 $3.3$）远低于 $\text{Fe}^{2+}$（约 $9.0$），便于后续调节较低 $\text{pH}$ 时使铁元素转化为 $\text{Fe(OH)}_3$ 沉淀彻底除去，同时避免主金属离子沉淀损失（定量对比见 [[卡片/铁铝铜离子的氧化转化与氢氧化物沉淀pH窗口]]）。
2. **调 $\text{pH}$ 步（自变量：加入含主金属阳离子的氧化物/碳酸盐/氢氧化物）**：
   - **中间过程**：溶液中存在 $\text{Fe}^{3+} + 3\text{H}_2\text{O} \rightleftharpoons \text{Fe(OH)}_3\downarrow + 3\text{H}^+$（及 $\text{Al}^{3+}$ 的同类水解沉淀平衡）。外加试剂（如 $\text{MnCO}_3$、$\text{CuO}$）与酸浸残留的 $\text{H}^+$ 反应，降低溶液中 $c(\text{H}^+)$，使溶液 $\text{pH}$ 升高至目标窗口；
   - **因变量（目的）**：促使平衡正向移动，使 $\text{Fe}^{3+}$、$\text{Al}^{3+}$ 完全转化为 $\text{Fe(OH)}_3$、$\text{Al(OH)}_3$ 沉淀过滤除去，同时主金属离子不沉淀且不引入新的外源杂质离子。

### 3. “不引入新杂质”的试剂配对总表
选择外加试剂时，同时核对**反应功能（氧化或耗酸）**与**产物归宿（变成水、逸出气体、进入滤渣或变成目标主离子）**：

| 目标主产物体系 | 氧化 $\text{Fe}^{2+}$ 的优选试剂 | 调节 $\text{pH}$ 除 $\text{Fe}^{3+}/\text{Al}^{3+}$ 的优选试剂 | 禁用试剂及原因 |
| :--- | :--- | :--- | :--- |
| **硫酸锰（$\text{MnSO}_4$）** | $\text{MnO}_2$、$\text{H}_2\text{O}_2$、$\text{O}_2$ | $\text{MnCO}_3$、$\text{MnO}$、$\text{Mn(OH)}_2$ | 禁用 $\text{NaOH}$、$\text{KOH}$、氨水（引入 $\text{Na}^+/\text{K}^+/\text{NH}_4^+$，且强碱易致局部碱性过强使 $\text{Mn}^{2+}$ 沉淀） |
| **硫酸铜（$\text{CuSO}_4$）** | $\text{H}_2\text{O}_2$、$\text{O}_2$（通热空气） | $\text{CuO}$、$\text{Cu(OH)}_2$、$\text{CuCO}_3$、$\text{Cu}_2(\text{OH})_2\text{CO}_3$ | 禁用 $\text{Na}_2\text{CO}_3$、$\text{NaOH}$、$\text{CaO}$（引入 $\text{Na}^+$ 或生成 $\text{CaSO}_4$ 微溶物混入产品） |
| **硫酸锌（$\text{ZnSO}_4$）** | $\text{H}_2\text{O}_2$、$\text{O}_2$ | $\text{ZnO}$、$\text{ZnCO}_3$、$\text{Zn(OH)}_2$、$\text{Zn}_2(\text{OH})_2\text{CO}_3$ | 禁用异种金属碱性物及可溶性强碱 |
| **氯化铁/亚铁（$\text{FeCl}_x$）** | $\text{Cl}_2$、$\text{H}_2\text{O}_2$ | $\text{Fe}_2\text{O}_3$、$\text{FeO}$、$\text{FeCO}_3$、$\text{Fe(OH)}_3$ | 禁用 $\text{HNO}_3$ 或 $\text{KMnO}_4$（引入 $\text{NO}_3^-$、$\text{K}^+$、$\text{Mn}^{2+}$） |

### 4. 审题必查的高频漏检要素（防坑清单）
1. **前序“过量”试剂的后效**：
   - 若步骤①注明“**过量**稀硫酸酸浸”，则进入调 $\text{pH}$ 步骤的溶液含有大量游离 $\text{H}^+$，加入 $\text{MnCO}_3$ 时首先发生 $\text{MnCO}_3 + 2\text{H}^+ = \text{Mn}^{2+} + \text{CO}_2\uparrow + \text{H}_2\text{O}$ 消耗游离酸；
   - 若氧化步加入了“**过量** $\text{H}_2\text{O}_2$”，而后续工序需加入还原剂或测定某还原性离子含量，必须先通过加热煮沸（使 $\text{H}_2\text{O}_2$ 分解为 $\text{H}_2\text{O}$ 和 $\text{O}_2$）消除残留过氧化氢的干扰。
2. **“趁热过滤”的双重目的**：
   - 当主金属盐（如高浓度 $\text{MnSO}_4$、$\text{FeSO}_4$）在低温下易析出结晶水合物时，趁热过滤可**防止温度降低导致目标产物结晶析出留在滤渣中，减少产率损失**；
   - 此外，较高温度可降低溶液黏度并促进 $\text{Fe(OH)}_3$、$\text{Al(OH)}_3$ 胶体状沉淀聚沉，**加快过滤速率**。
3. **调 $\text{pH}$ 范围的开闭区间规范**：按 [[卡片/溶度积Ksp与离子完全沉淀的pH定量判据]] 计算出下限 $a$ 与上限 $b$ 后，书写为 $a \le \text{pH} < b$（或文字表述为“$a \sim b$ 之间”），注意主离子开始沉淀的右端点 $b$ 取严格小于号。

### 5. 方法失效边界与替代方案
- **失效边界一（沉淀窗口重叠）**：当某杂质完全沉淀所需 $\text{pH}$ 高于主金属离子开始沉淀的 $\text{pH}$（如含 $\text{Al}^{3+}$ 与 $0.10\text{ mol}\cdot\text{L}^{-1}\text{ Cu}^{2+}$ 的混合液，前者完全沉淀需 $\text{pH} \ge 5.00$，后者在 $\text{pH} = 4.67$ 即开始沉淀），一步调节 $\text{pH}$ 无法实现完全分离，需改用有机萃取剂分步萃取，或利用 $\text{Al(OH)}_3$ 的两性将其转化为 $[\text{Al(OH)}_4]^-$ 进入滤液后再酸化回收。
- **失效边界二（钙镁氟化物/硫化物的酸性回溶）**：若流程中改用 $\text{NaF}$ 沉淀 $\text{Ca}^{2+}$、$\text{Mg}^{2+}$（生成 $\text{CaF}_2$、$\text{MgF}_2$）或用硫化物沉淀重金属，溶液 $\text{pH}$ 不能过低；因为在强酸性条件下，$\text{F}^-$ 或 $\text{S}^{2-}$ 会与 $\text{H}^+$ 结合生成弱电解质 $\text{HF}$ 或 $\text{H}_2\text{S}$，导致 $c(\text{F}^-)$、$c(\text{S}^{2-})$ 下降，使难溶氟化物或硫化物沉淀不完全。

### 下次探讨
1. **调 $\text{pH}$ 固体过量时的滤渣成分追踪**：在菱锰矿制备 $\text{MnSO}_4$ 流程（见 [[卡片/例题-硫酸锰浸出液氧化除铁铝的pH范围计算与试剂选择]]）中，为了确保反应充分，工业上常加入稍过量的难溶 $\text{MnCO}_3$ 粉末调节 $\text{pH}$。此时过滤所得的“滤渣 II”除了 $\text{Fe(OH)}_3$ 和 $\text{Al(OH)}_3$ 之外，还含有什么物质？这层未反应完的物质该如何循环利用？
