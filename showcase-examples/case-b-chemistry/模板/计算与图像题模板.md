## 参考理解
<!-- 填写说明（模板列出写卡时要注意的要素，按内容自然组织，不要求每张卡机械补齐同一排子标题）：
【1. 本类核心关注点（题设与目标如何导向突破口及失效边界）】
- 触发信号与突破口形成：说明题干文字（“恰好完全沉淀”、“开始沉淀”、“主金属离子不沉淀”）或图像转折点怎样翻译为临界浓度等式/不等式（c(杂质) = 1.0 * 10^-5 mol/L、c(主离子) = c0）；
- 建立平衡常数到目标量的代数变形链：写出难溶氢氧化物 M(OH)n 的溶度积表达式 Ksp = c(M^n+) * c^n(OH-)，依次完成“代入临界浓度 → 开 n 次方求 c(OH-) → 取负对数求 pOH → 由 Kw 换算临界 pH”；
- 区间合并与失效条件：下限取各杂质完全沉淀 pH 的最大值（max），上限取主金属离子开始沉淀 pH 的最小值（min）；指明非室温（Kw != 10^-14）或下限大于上限（无法仅靠调 pH 分离）时的失效边界。

【2. 高频漏检与防坑要素】
- 必查主金属离子的初始浓度 c0：计算主离子开始沉淀的上限 pH 时，代入的是题干给定的实际初始浓度（如 0.10 mol/L 或 1.0 mol/L），切勿误代为 1.0 * 10^-5 mol/L；
- 必查化学式中 OH- 的下标 n：二价金属 M(OH)2 开平方（n=2），三价金属 M(OH)3 开立方（n=3）；
- 必查科学计数法指数可整除化处理：开立方前先将指数调整为 3 的整数倍（如 8.0 * 10^-33），开平方前将指数调整为 2 的整数倍（如 1.0 * 10^-12），避免指数运算出错。

【3. 白板与可视化推演建议】
- 优先使用 普通填空题挖空关键数值代入步与对数换算步，或用 figure/frames 组件展示随 pH 升高各金属离子浓度负对数 pc-pH 曲线的转折点。
