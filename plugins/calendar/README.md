# 学习日历（基础版）

参照 Pi 版 `packages/vault-core/src/calendar-data.js` 与 `packages/learning-ui/src/legacy/calendar-client.js` 的月历＋当天内容布局，重新接 DSH 原生标签和当前 Vault 索引。没有运行时绝对路径 import，不依赖 Pi 包。

侧栏“日历”打开独立原生标签。点击日期查看计划学习、到期问题和日记；“今天”同时保留此前尚未处理的事项。

## 当前支持

- 日记沿用 Pi 日期规则：`type: daily` 的 `date: YYYY-MM-DD`，或无显式 type 的根目录／`日记/` 下 `YYYY-MM-DD.md`。
- **计划学习**：新文件使用 `type: plan`，每项例如 `- [ ] 开始学习 [[导数定号]] 📅 2026-11-10`。旧 guide、带导读标记的原文件继续兼容。日期表示开课期限；只有条目自己的显式日期进入日历，不再从文件级 `scheduledOn` 或日记日期补日期。
- **到期问题**：卡片现有 `reviewPlans` 中明确安排的问题，显示问题正文与来源；不复制复访历史，不把只有旧排期而没有问题的卡片制造成新问题。点“继续讨论”追加到该学习集长期教师草稿，不自动发送或完成。
- 早于今天的未处理事项仍在今天显示原日期；已完成计划不滞留。计划执行仍通过原任务勾选，问题是否继续及下次安排仍由原复访记录决定。
- “改期”保存到原计划条目，或追加原卡的 continuation 记录；保留原认识、帮助程度和问题内容，校验文件 revision，拒绝过期操作。支持今天或以后的日期。
- 日历“今天”和改期使用运行时本地日期，与既有复访历史写入一致；浏览器不单独指定另一套日期时区。
- 普通笔记、资料目录、日记、长期路线和备课本的勾选框不进入待办；没有日期的计划仍留在原文。旧路线 `lessons[].scheduledOn` 不再生成“已排期课堂”，真实文件不批量改写。
- 勾选任务通过原有 Vault `toggleTask`，提交 revision 与原文，防止外部修改被覆盖；勾选不写掌握或复习记录。
- 参考理解、教师参考、参考答案、答案、提示区，以及折叠 details 中的任务不进入日历清单；日记正文复用资料阅读器，参考内容默认折叠。行内代码和公式里的日期只是示例，不作为排期。
- “写当天日记”仅在用户点击后创建 `日记/YYYY-MM-DD.md`，CAS 创建拒绝覆盖已有文件，再交给现有 Markdown 编辑器。
- 月历读取已建立索引，不重新扫描磁盘。正文只读取当前日记；多份日记均可打开，内嵌预览第一份。

## 边界

calendar 包拥有日期投影与 `notaraCalendar/view,reschedule`；读取现有 Vault 索引，改期复用 Vault CAS 和 scheduleReview。按原生工作区绑定目录；异步创建完成后若用户已切换课堂／工作区、日期或离开标签，不跳转新页面。索引投影v14识别 plan，并兼容旧导读，从旧缓存重建而不改写源文件。

本版不提供拖拽排期、循环任务、自动创建日记、系统通知或新任务数据库。页面可见时订阅 Vault 更新，并保留15秒索引检查。最多投影10000份 Markdown，超出或日期异常会提示。
