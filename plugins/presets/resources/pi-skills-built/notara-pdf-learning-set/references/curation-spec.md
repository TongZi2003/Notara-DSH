# 卡片、标题与解析细则

用于写卡、样卡定调和核验；不是每张卡必须照抄的栏目清单。资料与关系写法遵循 `notara-pdf-learning-set`，个人模板优先，用其中提示检查内容，不机械填表。

## 原子实体：能独立使用，也能独立纠错

一张 concept/method 只讲一个独立概念或方法。判断依据是：会 A 是否仍可能不会 B，错 B 是否不需要重学 A？若是，就拆开并用真实前序或横向联系表达组合；例如概念的定义与一个独立计算方法不拼成一张“大而全”卡。一个不可分割流程所需的条件、步骤与边界仍放完整，不把完整推导拆成失去语境的术语碎片。跨章反复使用的基础可以单列，不因短卡、挂题少而重新合桶。

名称以简短、通用、精确的学科术语为主，可用“标准主干（具体招式）”消歧，不拼接目录长句。不要为字数要求改坏“导数”等标准名称。教辅自造口诀在正文解释其对应机制，不直接当跨书主干名；原名保留便于回查。

## 具体例子的标题：题面记忆锚点与零剧透

做过的学生能认出是哪一例，未做的学生看不到隐藏解法。优先用原材料中的标志性函数、物质、装置、事件、特征常数和设问作题面记忆锚点，保留必要题号消歧。有真实考源才标考源。

原题未明说的辅助构造、试探取点、解题技巧或答案不进入标题和摘要；例如题干只要求比较两条曲线，不把将要用的“切线放缩”写进题名。“两曲线”也不能误写成数学专名“双曲线”。学科机制、方法归属在实体标签或参考理解中表达，标题不能代替题干。

文件名使用可移植字符，避免路径分隔符、冒号和竖线；双链别名不嵌入方括号。数学简写要保住运算意义：`x+a倍e^x` 与 `x+ae^x` 不同，`x减1平方` 不能写成 `x-1^2`，对数可写 `log5底2` 而不是混成 `log52`。能在正文用公式准确写清的，不强塞成长文件名。不按这些命名建议批量重命名旧资料。

## 最贴切挂接，不把主干重新连成完全图

先读父会话给定的真实实体路径清单，只将已存在且核实的 concept/method 写为知识双链标签；新发现的独立实体先交主会话补齐，不创造空目标。尚无实体的检索词可以保留普通标签。

单点例子挂最贴切实体；综合题、多问、跨模块实验分别挂实际用到的独立分支。上游知识若仅是下游方法的常规前置，就沿前序可回查，不重复陪挂全部祖先；若本例确实单独训练这个前置判断，可以并列挂接。难度、背景、母题或易错属性按需要使用普通标签，不凑固定数量。题目默认不互连，同源变式或有明确比较用途时保留有意义的横向引用。

## 参考理解：让发现路径和严谨推导成为一份解析

保留完整对象、条件、图表、选项与设问；跨页内容合在能独立理解的例子里。原书有解答就核对其实际步骤，原书错误不静默改题：客观保留原题，在参考理解中注明勘误依据与影响。AI 补解或另一方法明确来源。

从材料中能看见的现象、目标与已有条件开始，按学习者可能走通的次序展开。可以自然使用“我们”一起推敲，不强制统一开场白；贴合学科与资料的论述风格。解析中的每个关键构造或变形，都在发生处回答“为什么会想到”：哪里算不动、哪个目标或结构提示了它、需要先核对什么条件。不要一句“注意到／易知／整理可得”跨过决定选路的小判断，也不把常规代入全写成追问。

例如求导后，若目标是判断正负，应说明为什么先寻找可因式分解的结构；若引入比较点，应说明目标不等式如何提示该点、它能否代入、是否与另一点在同一单调区间。随后给出实际运算和成立条件，而不是另起“思路分析—完整答案—易错总结”把同一过程重复三遍。长例子的独立小问或另一有效方法可分段分标题，标题用于真实结构，不堆模板栏目。

真实分岔处讲清舍弃某条路的原因：是计算代价大，还是漏条件造成伪等价；不要凭空编造一次“学生常犯的错误”或假装尝试过失败方法。必要的第二解保留完整依据、适用边界与选路理由，不只写一个方法名。单元末简短点明触发点、最关键的判断及与前例的异同，帮助连成可复用认识，不再重复全解。

数学关注合法性、等价性、区间和严格边界；物理交代研究对象、过程、受力或守恒条件；化学交代物种、反应条件及守恒/检验依据；编程讲目标、不变量、接口、边界与运行证据；事件或病案分析区分材料事实、解释假设和替代解释。类比是帮助理解的线索，不能替代各学科自己的证明或证据。

## 导航与交付检查

资料导读保留章节顺序、页码、题号及卡片入口；可用中性提示指出某题有勘误，具体改正答案和反例放参考理解或教师参考，不提前泄露单题关键步骤。原书章节导航与跨章专题各有用途，不把专题清单冒充原书结构。

核验时先看题面与解析是否对应、关键选择能否接上、前提和补例是否成立，再看文字与格式。只有来源资料而无实际学生表达时，学生理解留空；已有学生笔记与讨论保留原话、帮助经历与认识变化。结构检查不能抹掉这些记录，也不能凭一次材料整理点亮学生关系。
