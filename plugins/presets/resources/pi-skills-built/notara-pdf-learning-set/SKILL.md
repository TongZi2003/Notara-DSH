# 资料整理与图谱构建

收到教材、讲义、试卷、PDF、笔记或其他材料时，按实际收到与可读取的范围保留原件、整理知识实体与具体例子，准备可回查的资料导读。明确不整理、不保存或限定范围时遵守并传递限制；单页或单个例子不扩成整份工程。

老师或整理会话保存材料、卡片与报告；有首页绑定时由首页维护长期画像与路线，无首页独立课堂自维护。内部工作员只返回局部草案与依据，不获得写入或再次委派权限。

整书、多本书或批量续拆时，先读 [骨架与批量整理](references/book-backbone.md)；写卡或核验卡片时，按需读 [卡片与解析细则](references/curation-spec.md)。两份参考补充教学取舍与协作方式，关系语法仍只以本 Skill 第 3 节为准。

## 1. 先读原件与已有内容，增量整理

- 原件保存在 `来源/`。宿主已有成功入库回执时复用真实路径，不重复复制；只有附件引用时先核实保存状态。原件入库、已读范围与整理完成分别报告。PDF保留页码/区域引用，无法核实坐标时不编造；缺页或不可读内容列待核对。
- 先用 `glob` / `grep` / `read` 查相关来源、卡片与导读，比较对象、条件、结论和用途；同一知识补充来源，有重要情境差异的具体例子独立保留。长日记先搜索定位再读相关小节，必要上下文完整读取。重复材料不重复建卡或追加相同记录，保留原有学生理解、复习记录和来源。
- “材料说了什么”与“为何如此”分开。前者对照原句，后者给出推导依据；仅凭材料类别猜作者身份、经历、动机或记录盲区，不能当事实。有价值的猜想用“可能……也可能……，需……来辨别”表达，没依据就省去，参考理解也遵守这一条件。学生记录只收本人的表达，教师提出的延伸问题归教师建议；已有学生笔记可保留理解与联系，不强制重教或测验。
- 写卡前 `read` 学习集内适合的 `模板/*.md`；缺匹配个人模板时读本Skill相对资源 `templates/card.md`，或 `templates/source-guide.md`、`templates/math-concept.md`、`templates/math-problem.md`、`templates/chemistry-process.md`、`templates/code-practice.md`。提醒按内容采用，不机械填满子标题，不覆盖个人模板或批量重写旧卡。
- 需要补充资料时核对公开权威来源、条件与出处，AI推演或改编注明来源。概括新方法前核对真实样本、边界和反例，不把单题经验当一般结论；复杂处按权限请现有调研或审核协助。
- 整书先比较章节推进与代表页，定原子骨架和标杆样卡，再按依赖并行处理独立页段。已明确的全量范围持续完成，不把试点冒充整书交付，也不重复要求确认；只需骨架时保留代表例子，不默认逐题精解。

## 2. 知识实体与具体例子

- `type: concept` 承载可复用的知识点、定义、定理、机制或制度，说明动机、条件、正反例及必要推导。
- `type: method` 承载可复用的方法，说明识别信号、选择理由、操作、代价与失效边界；有效的不同方法保留，样本不足就说明初步观察。
- 原子粒度看独立学习、使用与纠错价值：会 A 不等于会 B，或错 B 无需重学 A，就分别建实体；概念性质与独立操作方法不拼成大桶，同一不可分割流程保留完整语境。标题用简短标准学科名称，不因短卡或挂题少而合并；作者口诀放正文说明对应含义。
- `type: exercise` 沿用内部标识，对外统称“具体例子”：题目、实验、历史事件分析、医学病案分析等均可。按自身形式保留完整材料、情境、过程、解释依据与来源，不强填题干—标准答案—分数。值得独立回看的例子单独成卡，临时举例不强制建卡；长材料保留全文，局部设问带足上下文并回链总材料。
- 题卡标题用题干中可辨认的函数、物质、装置、常数与设问作为题面记忆锚点，不泄露原题未给的解法、辅助构造、测试点或答案。参考理解把“为什么会想到—实际推导—条件核对”自然串成一份解析；关键构造或变形就地说明触发线索，不先写一遍思路再重复答案。纯概念、代码、实验等保留各自学科表达与资料风格。
- `## 内容` 保留完整对象与条件，底部用“查看原页”折叠区收纳来源；`## 参考理解` 保存经核实的教师整理、完整推导、分析与不同解释；`## 学生理解` 保存实际表达、认识变化、探索、问题与贡献。新卡不带入旧 `learned/mastery/interval/last_review/next_review`，已有排期与历史不重置。
- **YAML Frontmatter `summary` 摘要**：新建 Markdown 资料（卡片、导读、模板等）时，在 Frontmatter 中与 `title`、`type`、`tags` 同级写入 `summary` 字符串，不另建正文摘要章节。用约 30～60 字的一句纯文本说明主题与用途，不含公式、代码、HTML 或双链；题卡只概括对象、条件与目标，不透露答案、突破口或提示；所有摘要均不评定学生掌握程度或复述学情。内容范围改变时同步更新，普通复习记录更新无需重写，保留仍准确的手写摘要，旧资料不批量补写。

## 3. 图谱权威写法：实体主干、例子挂接、个人经历分开

本节和 `templates/card.md` 是写入合同；其他教学Skill引用这里，不另写一套语法。系统从真实文件引用解析身份、关系与投影，模型只写已读引用及其意义。

**知识标签。** 具体例子的 `tags` 可包含实体双链字符串，普通年级、难度、背景或来源标签仍用普通字符串。例如：

```yaml
tags:
  - "[[卡片/均值不等式]]"
  - "[[卡片/柯西不等式|柯西]]"
  - 高二
```

先复用真实 `concept` / `method`，确有独立知识内容才创建完整实体，不为标签批量造空卡。缺失、非实体或同名歧义引用保留原文待维护，不凭相似名称猜目标；明确路径不能悄悄转挂同名文件。旧纯文本知识标签仍可检索，内容核实后才改实体引用。相同标签不等于相同用途或难度，标签关系不代表学生掌握。

批量起草以已读实体路径清单为挂接依据。单点例子挂最贴切实体，综合例子覆盖实际使用的独立分支；常规前置已由下游方法承载时，不机械陪挂整条祖先链。需要独立考察某个前置判断时仍可并列挂接，不按固定数量裁剪真实关系。

**直接前序。** 只在后继知识/方法实体B的根级小节中声明；下例生成A到B的前序。直接列表写清本任务或方法路径使用的具体判断：

```markdown
## 前序依赖

- [[卡片/共同基础]]：各路线都会使用的判断。

### 路线：同支比较
- [[卡片/导数与单调性]]：用于本路线的区间比较。
- [[卡片/定义域与范围推导]]：确认比较点合法。

### 路线：另一方法
- [[卡片/另一方法的基础]]：本路线实际使用的依据。
```

未分组项是共同前序，同组联合使用、组间替代；没有多路线就只写直接列表，不制造分组。仅 `concept` / `method` 参与主干，例子的步骤依赖、实验流程和事件时间线留在原分析或课稿中。普通互链、同标签、同章出现和本课顺序不生成前序。声明写在代码、折叠教师参考、引用和嵌套列表之外。只写有依据的直接关系，不补间接祖先；已声明的直接关系不能因另有可达路径删除。循环保留原文，不为凑树删边或阻止学习，实际维护时核对原因。

**横向联系。** 比较、类比等放根级 `## 横向联系` 的直接列表，需要区分同对实体不同关系时用三级主题：

```markdown
## 横向联系

### 主题：条件比较
- [[卡片/另一方法]]：说明相似处及不同条件。
```

普通双链仍是引用，来源仍表达出处。旧无限定学生联系保留为一般联系，不自动升级为前序或知识标签；无新声明的旧资料仍可回查，不在打开时全库重写。

**学生对具体关系的理解。** 在所属卡的 `## 学生理解` 下，用 `### 已建立的联系` / `### 待探索的联系` 的直接列表定位关系：

```markdown
- [[卡片/A]]（前序依赖）：本实体共同前序A的理解与真实来源。
- [[卡片/A]]（前序依赖／同支比较）：本实体该路线前序A的理解与来源。
- [[卡片/实体]]（知识标签）：当前例子挂接该实体的理解与来源。
- [[卡片/目标]]（横向联系／条件比较）：该主题联系的理解与来源。
```

新限定只改变已经存在的对应关系，不补造依赖；同一对实体的前序、路线与类比分别维护。帮助后形成的真实联系也可记已建立，教师单方说明仍放参考理解。已有关系上继续追问放“下次探讨”，不因此撤回关系；真正更正或撤回只调整对应关系，保留原话、更正经过及日记定位，无法无歧义对应时保留原记录待核对。来源与折叠历史链接不声明当前联系，也不按一次表现点亮例子的全部标签。

## 4. 资料目录、保存与交付

- 资料目录用 `type: source`，以普通链接列表组织章节、原页与卡片，不生成任务勾选框。旧 guide 与原导读继续兼容。具体学习安排使用 `type: plan`，长期方向归 `type: route`，单课备课与课内任务归 `type: lesson`。仅整理资料不自动安排个人日期或课堂；小范围整理复用已有文件。
- 边拆边学时，当前老师可沿已有会话轻量讨论，无需完整备课本；其他会话把问题交相关teacher。收到资料不默认启动专题备课；完整单课才用 `notara-lesson-preparation`。仅整理时直接交付，学生已经要求拓展则核实来源后承接，教师补充与学生实际表达分别保存。
- `write` / `edit` 后逐一 `read` 核实真实路径、Frontmatter摘要、内容与引用，失败如实保留草稿或部分完成。清单写明处理范围、新增/更新文件链接、来源定位、未处理部分与待核对项。
- 独立整理收口时将清单保存到 `type: diary` 日记的本次整理小节，再 `read` 回读，按当前角色已有的 `lesson_summary` 工具 schema 以 `materials` 交付；宿主追加日记索引，按真实绑定通知首页，暂无首页先保留持久回执。内部任务向直接父老师返回依据，由父老师汇总，无需自写日记。
- 纯整理不产生新学情或作答，已有学生笔记按来源保留；仅整理请求交付真实清单即可结束，不安排测验。正式复习继续走学生确认，整理不改排期。
