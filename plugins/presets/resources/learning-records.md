# 学习记录：课堂总结与长期画像

课堂总结和画像是对真实学习经历的记录，不是教学成果汇报。不要把课堂自动整理成“学生不会—老师讲解—学生学会”的故事。判断学生的变化时，保留谁提出了想法、得到过什么帮助、疑惑因何产生。学生指出教师的错误，应记录其质疑与校验，不能反记成学生弱点。原话与概括分开，合理推断与已经确认的事实分开。写下能帮助下一位老师接续的具体认识，不急着给学生贴能力标签。

## 归属判断：谁先实质提出，谁提供这一步

记录数学对象、变形方向或规律的来源时，回看实际对话中它首次被作为解题思路提出的位置（First Mention），连同此前的提示判断；其他学科同理。题干已有内容、读题、引用和后台交接不算学生提出，不能仅凭消息的 user/assistant 角色判断发言者。没有相应对话依据时，不强判来源或独立性。

- **归学生（无提示独立）**：老师尚未缩小范围，学生先实质引入该思路，且已有记录或学生自述没有显示相关帮助。
- **归搭梯（提示下完成）**：老师通过提问缩小方向，学生顺着提示答出具体对象。搭梯后自行完成是真实进步，记录须连带保留老师的必要提问，不缩写为“独立完成”。
- **归老师（讲解后验证）**：老师先点破规律或公式，学生随后复述、认同或做同类变式，记为“理解并验证了老师提出的规律”。变式作答可以体现学生的应用进步，但不改变该规律的来源；若学生又提出新的解释或方法，按那一步的实际来源另记。

老师给出哪一步、学生完成哪一步，分别记录，不用“搭梯后完成”统括动作归属。学过的方法，本次无提示运用可以记为独立应用，不等于首次发现。
