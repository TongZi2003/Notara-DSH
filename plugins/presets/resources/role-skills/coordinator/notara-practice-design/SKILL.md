# 选例与活动设计

需要从资料或已导入题库选择具体例子，编排练习、实验、分析或探索活动时使用；组卷是其中一种用途。首页交清目标、时长、资料与学情，具体选择和编排由老师负责。已有一个明确例子时可直接讨论，不强制先选例或备课。

## 1. 核实具体材料与学习价值

先明确这些具体例子要帮助学生形成什么认识、方法或作品。读取例子的知识标签及其对应知识实体，再读题干与解答、实验设置与观察、历史事件材料与分析、医学病案材料与推理依据，核实真正用到的方法、条件和关键小判断。相同标签不等于学习价值相同，标签多也不等于难度高；关系写法按需查 `notara-pdf-learning-set` 与卡片模板，不在这里复制语法。

优先复用已导入材料，保留完整情境与出处；拼接改编或原创注明改动并完整自解/核验。资料包中他人的作答和学习痕迹不变成当前学生的记录。资料不足时说明缺口，不凭标签臆造题面或学生弱点。

## 2. 每个例子承担明确作用

- 按目的选择引入现象、条件比较、方法选择、组合应用、反例、迁移或作品改进，说明为什么选它、前后怎样连接及何时提供支撑；不为凑难度或标签覆盖堆题。
- 学生可以借助AI计算、代码或资料继续做选择、解释与质疑，分别记录实际贡献。前置用于选择支撑位置，不要求先测过所有前序才能探索；考试补强与独立能力评估才安排对应的新题、限时或迁移检验。
- 考试补强结合当前错因画像选题；原因需要辨明时沿 `notara-error-analysis`，不在这里另做归因。题目要能触发需要调整的判断或习惯，通过条件对比、适当变式或组合任务观察其变化；同知识标签不等于同一补强目标。
- 从学生实际探索、解释、结果或作品变化决定下一步：顺畅则深入或换情境，受阻就补最影响推进的一步，目标变化则调整范围；没有新变化复用已有记录，不强造进步。
- 需要选材依据或独立核对时用现有 `worker-general` / `worker-review`，按依赖组织并行串行；简单选例不强制走满工作员。完整单课沿 `notara-lesson-preparation` 保留主老师定主线、调研供依据、审核读最终稿的分工，不另派第二套备课流程。

## 3. 保存与交付

题组或练习卷复用任务型 `type: lesson` 与题卡。先读个人模板，缺失时读本Skill的 `templates/lesson.md` / `templates/card.md`；公开部分保留完整题面、原有条件、出处与作答安排，参考答案、解法和教师观察标尺全部放进独立成行的 `<details data-notara="teacher">` 折叠区域。“参考答案（做完再看）”这样的标题本身不会折叠内容，不能代替该区域。保存回读时核对答案确在折叠区域内；不新增卷子实体类型。

保存后 `read` 回读，提供真实文件链接。只要求组卷时交付后结束，按 `lesson_summary` 工具说明用 `preparation` 交付，不写虚构学情或调用 `set_current`。实际进入课堂时才按需要 `lesson_plan` 绑定本课清单；讨论探索用 `question`、训练授课用 `lesson`，记录真实认识变化、问题、产物、各方贡献与续接位置。正式复习仍由学生确认，不随制作或探索自动改排期。
