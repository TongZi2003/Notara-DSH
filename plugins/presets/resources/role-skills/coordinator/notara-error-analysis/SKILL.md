# 错因分析

面向考试的错题复盘、练习或课堂评估中，出现值得理解和补强的错误、误区或反复受阻时使用。围绕当前题目复原学生当时怎样想、怎样做，从知识与方法、熟练度、心理与考试状态交叉理解原因，形成当前错因画像与可执行的改进动作，供针对性备课使用；普通探索不因此变成逐项挑错。

## 1. 带着原题、作答与草稿进入

先看完整题设、学生原作答、批改和可用草稿，定位错误，也保留已经成立的部分。外部已经批改或复盘确认的考试、作业错误，作为较强的补强依据；课堂评估中的误区同样进入分析，结合当时任务、提示和后续表现判断。多次独立表现的相互印证可以提高判断把握，不只按“外部／课堂”固定高低。

确认错误发生与确认错因是两回事。批改确认错了，并不自动说明是不会、没想到还是当时漏做；原卷空白、别人作答或标准答案也不能代替学生自己的过程。字迹或符号看不清时先请学生确认。按当前问题检索相关旧题、日记与画像，看看是否有相近经历及已奏效的帮助，不只依赖这一次结果。

## 2. 先回忆当时怎么做，再讨论现在怎么改

让学生顺着原作答和草稿讲当时的过程，例如：“看到这个条件，你第一反应是什么？沿着草稿说说，后来为什么走到这一步？”根据回答再追最关键的一两处：注意到了什么、想调用哪个旧方法、为什么放弃另一条路、哪里犹豫或跳过、时间压力是否改变了做法。不把每道题都变成同一套问卷，也不先讲完标准解再要求学生复述。

草稿中的图、尝试、划掉的式子和转向都能提供线索。结合学生说明重建其选择顺序；草稿缺一步不直接等于脑中没有这一步。学生记不清时保留现有线索，转到当前的小判断或相近任务观察，不替他补出一段确定的回忆。

## 3. 多维诊断，老师主动猜测并与学生辨明

老师可以根据过程提出有依据的猜测，帮助学生看见自己习惯性的联想或操作。例如：“你当时是不是沿用了方程两边同做运算的想法，没有另外考虑不等号方向？还是知道要变号，但这一行漏掉了？”让学生补充或否定，必要时用一个小判断区分几种解释，并先提供能继续的帮助。

根据当时过程交叉看几个维度，不强迫归入唯一类别：

- **知识与方法**：概念、条件或前置知识是否遗忘；看见题面后能否联想到可用方法；熟悉经验是否用过了范围；是否存在学生能理解的、更简洁稳妥的路径。不要止于“这道题考哪个知识点”，要找到具体断开的联系或缺少的判断。
- **熟练度**：在选路和关键依据基本清楚后，计算、变形、表达、自检能否顺畅执行；卡住的是哪一个操作。做得慢不直接等于练得少，也可能是路线太绕或每步都在重新寻找依据。
- **心理与考试状态**：结合学生回忆，看紧张、怕错、信心或时间压力怎样影响了当时的选择、书写和检查。它们可能独立起作用，也可能由“不知道该用什么、前置知识想不起来”带出；只靠错误数量不能确定心理原因。

对“慢、慌、做不下去”等表象再追一步，优先核对选路是否合适、必要知识是否能调用。换一条可理解的简洁路径后若顺畅了，补强重点应回到知识联系与策略；路径和依据都清楚、操作仍迟缓时，再安排适量熟练训练；平时能完成而限时失常时，结合具体过程调整节奏与应对方式。保留各因素怎样相互影响，不用“粗心”“心理问题”提前结束分析。

学生回忆、草稿事实和老师的解释分别归属；有根据的教学假设可以指导下一步，说明依据并留给学生确认或后续任务辨别，不冒充学生已经发生的思维过程。

## 4. 把原因落成一个能练的动作

每道题先抓最值得改变的一处，不止留下“粗心”“基础薄弱”等笼统标签。说明在什么情境下应该注意什么、做哪个动作，并结合本题示范，再让学生在适当变式中自己使用。

例如，若学生会求导，却在需要判断导数符号时没有继续整理，应补的是“为了判号，先看式子能否因式分解并定位零点”，不必重新上一遍求导课。若只是负号偶然抄错，可以用一处核对动作收束；若反复在限时后半段丢条件，就结合实际用时讨论检查、跳过与返回的安排。习惯引导服务于解题，不追加一套处处打勾的仪式。

## 5. 长期维护错因模式，用于针对性备课

具体题目的回忆、草稿线索、当次误区、有效帮助与改进动作，保存在已有题卡的学生理解或当前课堂／日记报告，链接原作答；教师猜测明确归于教师解释，尚未确认的主观动机不写成学生事实。没有续接价值的小失误无需单独建卡。纯诊断沿 `question` 交付，课堂训练沿 `lesson` 交付，保存后 `read` 回读并按 `lesson_summary` 工具说明提交（长期教师侧按 `notara-quest-orchestrator` 接收维护）。

有首页时，由首页结合报告维护已有 `learner-profile`，按需加入“当前考试错因与补强重点”小节；无首页的独立老师沿原职责自维护。画像归纳跨题的当前错误模式、常见触发情境、知识／熟练度／考试状态的作用、判断依据和有效改进动作，具体题目及草稿沿链接回查，不另建错因实体或数据库。单次有教学价值的错误可记为当前卡点，不直接升格为稳定习惯；已确认的模式与有作答依据的暂定教学判断说清区别，不强制打置信分数。动机、性格等主观猜测先与本人核实，不长期存成标签。

长期跟踪结合新的错题、课堂评估和复习结果进行：看同类情境下是否仍出现、什么帮助有效、是否开始自行采用改进动作。已有改善、适用范围变化或原因被推翻时更新当前判断，保留来源与必要演变；没有新情况就复用原记录。既写仍需补强的部分，也写已经形成的有效习惯。普通探索无需建立这份考试小节，也不被既往错因限制新的学习方向。个人模板优先；需要新建普通画像或题卡时可参考 `templates/learner-profile.md`、`templates/card.md`。

诊断交付要让备课老师知道“最值得改变什么、依据在哪、哪种帮助已经奏效、还有哪处需要观察”。首页把相关错因模式及本次目标交给老师；老师沿 `notara-practice-design` 选题、沿 `notara-lesson-preparation` 把它组织成一节课：知识断点用合适的引入与搭梯补上，选路问题用对比和变式形成触发意识，操作与考试节奏在需要时安排练习，并观察学生是否开始自行使用改进动作。相同知识点可以因错因不同而采用不同课程，相同错因也可以跨题比较，不只是多刷同标签题。只备课时沿 `preparation` 交付，不提前记录补强成功。

首页负责理解交付和维护画像，具体回忆访谈、单题引导与补强由老师开展。内部工作员只依据分配材料返回分析、可能解释和建议，由父老师与学生核实并保存，不直接询问学生、写画像或再次委派。新的误区不自动变成正式作答记录；实际学习与下一次回访沿 `notara-review-brainstorm` 保存，老师选择具体问题和时间，正式作答结果仍由学生确认。
