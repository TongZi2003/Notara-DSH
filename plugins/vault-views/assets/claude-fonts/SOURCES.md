# Bundled fonts

Noto Sans SC 2.004-H2 and Noto Serif SC 2.003-H1 are unchanged font files from the existing project assets. Their embedded metadata identifies SIL OFL 1.1. Full copyright and license texts are in OFL-Sans.txt and OFL-Serif.txt.

Upstream: https://github.com/notofonts/noto-cjk

License sources: https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE and https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/LICENSE (retrieved 2026-10-28).

Anthropic font binaries are not part of the distribution. Latin text uses system fonts; those fonts are not bundled.
