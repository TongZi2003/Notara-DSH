# Notara · DSH 学习插件

**让你的知识地图越来越亮、越来越宽广、越来越深刻。**

通用工作 Agent 想的是替你把事情做完；学习 Agent 更重要的任务，是帮你自己想明白。

教材在 PDF 阅读器里，草稿在纸上，讨论在聊天框里，笔记又在另一个软件里。每次提问都要重新搬背景，聊明白的东西过几天又找不到了。Notara 想做的不是发明学习捷径，而是把这些工具接到同一张书桌上，让有价值的讨论留下来，下一次还能接着学。

这是基于 **DSH（DeepSeek Harness）** 的学习插件组，不是独立桌面安装器。课堂使用 DSH 原生会话，资料保存在本地 Markdown、PDF、Canvas 等文件中。

## 一慢一快，两条路

有整块时间，就先整理资料、备好课，再开专题课堂；只是卡在一道题上，也可以直接问。两条路最后都回到真实的学习记录，由长期教师接上下一步。

```text
长期教师：对齐目标，了解起点，调整下一步
    │
    ├─ 系统学习：整理资料 → 路线与备课 → 专题课堂 ─┐
    │                                           │
    └─ 轻量讨论：一个疑问、一次错因回顾或自由探索 ─┤
                                                ↓
                         卡片与日记：收获、卡点、下次可以继续
                                                │
                    长期教师据此调整后续安排 ←────┘
```

### 学习前：先铺地图，再决定怎么走

- **整理资料**：从教材、笔记、试卷或已有讨论中拆出知识单元，保留题设、推导和来源。概念与方法构成前序依赖主干，题目、实验和其他具体例子挂接在相应实体上。
- **个性化备课**：结合 **A 手头资料 + B 有记录的学情 + C 本次目标、时间与偏好**，先确定整节课要跨过哪道坎，再选有递进关系的材料。备课本既有公开任务，也有折叠的教师参考。

### 学习中：把最后一步留给自己

- 能直接讲清的就讲清；需要思考的先尝试，卡住后再给具体台阶。关键不只是“怎么解”，还有“怎么想到、什么时候能用”。
- 阅读器、PDF 选区、函数图、白板与共绘按需使用。学生也可以邀请同学讨论，或选“不看解析”的同学听自己讲题。
- 普通疑问和节外生枝的探索不必先变成一堂完整的课，也不必每次都加一场考试。

### 学习后：留下真实变化，而不只是标准答案

- 分清学生先提出、提示后完成和听讲后验证；经过帮助形成的理解同样值得记录。
- 图谱区分来源、前序依赖、横向联系与例子挂接；知识联系的虚实线表示是否已有具体的建立记录，不是一个笼统的“掌握分”。
- 回访不是机械重做原题，而是留下**下次可以继续的具体问题**，由老师结合实际情况安排时间。学习计划的日期条目和卡片到期问题进入日历。

## 安装，然后跑通一次学习

当前源码版本为 **0.1.2**，适配 **DSH 0.2.1-rc.4**，需要 **Node.js 24+（含 npm）**。**npm 的 0.1.2 尚未发布**，先按源码路径安装，不要把 npm 上的旧版当作这次更新。

```sh
git clone https://github.com/TongZi2003/Notara-DSH.git
cd Notara-DSH
npm ci
npm run pack:plugins -- release/0.1.2
```

接下来按 [安装与启动](docs/INSTALL.md) 的第 2 步安装到独立目录、配置资料路径并启动。打包命令会构建全部插件；不要共用正在运行的 DSH 依赖目录。

- **[安装与启动](docs/INSTALL.md)**：从空目录到打开实际界面，配置模型与学习集。
- **[第一次学习与日常用法](docs/USAGE.md)**：用仓库里的原创导数材料，跑通“提问 → 学习 → 保存 → 续接”；也可以直接换成自己的问题。
- **[发行与升级](docs/RELEASE.md)**：已有安装的升级边界、宿主适配与维护者打包说明。

第一次用不需要准备整本书，也不用背 Skill 名称。先告诉老师：你想弄懂什么、现在会到哪里、今天有多少时间。

## 开发入口

共七个功能插件及一个 bundle，包名沿用 `@oh-my-student/*`。

```sh
npm run build
npx playwright install chromium
npm test
```

`npm ci` 和构建会校验并应用本安装目录内的 DSH 宿主适配。测试包括图谱/互动块的浏览器检查；完整课堂与真实模型验收另行进行。

| 目录 | 内容 |
| --- | --- |
| `plugins/` | 教学预设、Vault、资料工作台、图谱、日历、计时器与 bundle |
| `prompts/` | 提示词与 Skill 的权威源；构建时同步到 presets |
| `templates/` | 文档模板与原创起始学习资料 |
| `showcase-examples/` | 合成学情与教学测试材料，不是真实学生档案 |
| `examples/lesson-preparation/physics/` | 原创物理备课样例 |
| `scripts/`、`tests/` | 构建、打包、宿主适配与回归检查 |

[来源与第三方说明](docs/PROVENANCE.md) 列出移植来源、字体和素材边界。

## 数据与使用边界

学习资料以本地文件为准，SQLite 是可重建索引。使用远程模型时，实际读取的资料、图片与对话会发送给所选模型服务商；本地存储不等于完全离线。模型服务需自行配置，并可能产生费用。不要提交密钥或真实学生资料。

模型仍可能算错、遗漏条件或把老师的提示记成学生的发现。发现记录不实，可以直接要求回读、更正；自动排期也不等于能精确预测遗忘。

本仓库不分发商业教材、教材拆解学习集、真实课堂轨迹或个人画像。内置样例是原创材料或合成学情。Windows 安装及跨平台完整课堂尚未完成实机验收。
