# Notara · DSH 学习插件

**让你的知识地图越来越亮、越来越宽广、越来越深刻。**

通用工作 Agent 追求的是替你直接交付结果；而学习恰恰相反——那些不能被省掉的推导、试错、卡壳与顿悟，才是真正长到你自己身上的东西。Notara 是一套运行在 **DSH（DeepSeek Harness）** 上的学习插件组，目标不是替你写完作业，而是降低「阅读材料—加工思考—沉淀记录」之间的工具摩擦，陪你从 0 开始长出一张属于自己的知识地图。

平时看书和做题时，教材在 PDF 阅读器里，演算在草稿纸上，讨论在对话框里，笔记又散落在另一个软件里。每次提问都要重新交代前因后果，聊透的思路过几天就淹没在历史记录中。Notara 把阅读器、批注、函数图、白板、长期记忆和本地 Markdown 资料库接在同一张书桌上，让每一次有价值的讨论都能沉淀下来，下一次打开还能接着往下走。

## 核心学习闭环：一慢一快，两条路径

无论你有整块的自学时间，还是在日常作业间隙只想弄懂一个具体卡点，最后都会汇入同一份真实的学习记录，由长期教师接上下一步：

```text
首页学习助手（长期规划与接续：对齐目标、了解起点、安排下一步）
    │
    ├─ 系统学习（慢路径）：整理资料 → 路线与备课 → 专题课堂授课 ─┐
    │                                                           │
    └─ 按需讨论（快路径）：单题答疑、错因复盘、整理笔记或自由探索 ─┤
                                                                ↓
                                     卡片与日记沉淀：真实理解增量 + 下次继续的问题
                                                                │
                                  首页学习助手结合回访排期接续 ←──┘
```

### 1. 学习前：拆解资料骨架，先备课再开讲

- **主页总控与课堂委派**：在「首页学习助手」里聊长期目标、学习进度和今日安排；确定要啃哪块内容后，由它委派独立的「专题课堂老师」或「资料整理助手」去执行，避免单次长对话冲淡长期上下文。
- **分层整理资料**：从教材 PDF、课堂笔记、试卷或讨论中拆出最小知识单元，完整保留原题、推导和出处链接。**概念与方法**构成带前序依赖（`prerequisites`）的主干骨架，**题目、实验和具体例子**通过知识标签（`knowledge_tags`）挂接在主干上。
- **A+B+C 备课缓冲层**：面对跨度较大的专题，老师会结合 **A 手头资料 + B 已有学情记录 + C 本次目标、可用时间与偏好**，先编排一份包含「公开学习任务」与「折叠教师参考」的备课本（`type: lesson`），想清楚整节课怎么搭台阶，再开始正式授课。

### 2. 学习中：把关键一步留给自己，工具按需出场

- **搭台阶式互动**：基础背景和概念直接讲清；到了需要动脑的关键跨越处，先让你在草稿纸上尝试，卡住时再顺着你的实际步骤给出一小步提示，重点追问「怎么想到这一步、换个条件还成不成立」。
- **多模态工具随叫随到**：平时只需一个清爽的对话框；遇到复杂结构时，可以在对话里直接生成交互函数图与几何示意图，打开 `.canvas` 课堂白板分栏对照推导，在 `.excalidraw` 画板上和老师同屏共绘，或是点开「请同学 → 讲给同学听（不看解析）」请虚拟同桌听你讲一遍题，检验自己是不是真的讲得通。

### 3. 学习后：记录真实认识变化，在快要遗忘时带着新问题回访

- **诚实区分动作归属**：课后沉淀到卡片「学生理解」里的，不是套话或标准答案抄录，而是你这节课**自己先想到了哪一步、哪一步是在提示后补齐的、还剩哪个具体疑问**。
- **可生长的虚实图谱**：在双链之上区分「来源归属、前序依赖、横向关联、例子挂接」。你还没有真正走通的知识联系在图谱上显示为**虚线**；当你通过推导或做题真正建立起联系后，这条边才会点亮为**实线**。
- **动态复习与追问演进**：系统会根据你本次是独立做出还是依靠提示，动态计算下次复习间隔（1 / 3 / 7 / 16 / 35 天升级，遇到卡点则缩短回访），并把**下次可以继续探讨的具体新问题**放进待复习队列与学习日历，让每次回访都在往前走一步。

## 快速开始

当前源码版本为 **0.1.2**，适配 **DSH 0.2.1-rc.4**，运行环境需要 **Node.js 24+（含 npm）**。由于 **npm 上的 0.1.2 尚未发布**，请直接从本仓库源码构建并安装到独立目录：

```sh
git clone https://github.com/TongZi2003/Notara-DSH.git
cd Notara-DSH
npm ci
npm run pack:plugins -- release/0.1.2
```

生成 `release/0.1.2` 发行目录后，按以下指南完成安装与首次体验：

- **[安装指南（docs/INSTALL.md）](docs/INSTALL.md)**：从空目录开始完成独立环境安装、资料库路径配置、启动与模型接入。
- **[使用指南（docs/USAGE.md）](docs/USAGE.md)**：用仓库自带的原创导数学习集，完整走通一次「提问 → 课堂学习 → 记录沉淀 → 下次续接」，并了解日常整理资料、备课与随手提问的用法。
- **[发行与升级说明（docs/RELEASE.md）](docs/RELEASE.md)**：已有环境升级、宿主适配校验与发行打包说明。

第一次打开时，不需要先把整本教材导进去，也不用记任何指令名称。直接打开「首页学习助手」，告诉它你想弄懂什么、现在会到哪里、今天有多少时间即可。

## 仓库结构与本地开发

本仓库包含七个功能插件与一个聚合 bundle（包名作用域为 `@oh-my-student/*`）：

```sh
npm run build
npx playwright install chromium
npm test
```

`npm ci` 与 `npm run build` 会自动校验并应用当前目录内 DSH 依赖的宿主适配补丁。测试套件包含针对插件构建、文档链接、图谱渲染与交互组件的自动化检查。

| 目录 | 说明 |
| --- | --- |
| `plugins/` | 教学角色预设、Vault SQLite 索引、资料工作台视图、知识图谱与互动组件、学习日历、番茄钟及聚合 bundle |
| `prompts/` | 角色提示词与教学 Skill 的唯一维护源，构建时自动同步至 `plugins/plugin-presets` |
| `templates/` | 卡片/画像/路线/备课本模板，以及原创导数起始学习集（`01-derivative-methods`） |
| `showcase-examples/` | 用于展示与回归测试的合成学情样例 |
| `examples/lesson-preparation/physics/` | 原创高中物理备课本样例 |
| `scripts/`、`tests/` | 构建脚本、发行包生成、宿主适配工具与自动化测试 |

第三方依赖、开源组件与素材来源详见 **[来源与第三方说明（docs/PROVENANCE.md）](docs/PROVENANCE.md)**。

## 数据归属与使用提示

- **本地纯文本优先**：你的所有卡片、学习画像、路线计划、日记与白板均以普通 Markdown（`.md`）、JSON Canvas（`.canvas`）和 Excalidraw 文件保存在你指定的本地资料目录中，随时可以用 Obsidian 或任意文本编辑器直接打开；SQLite 仅作为可随时重建的本地加速索引。
- **模型服务与隐私**：你需要自行配置所选大模型服务的 API Key 或账号。对话过程中实际发送或读取的文本与图片会传给所选模型服务商，请勿在公开仓库或 issue 中提交 API 密钥与个人隐私资料。
- **与 AI 共同校准记录**：受限于当前大模型的推理能力，老师偶尔仍可能算错步骤，或在课后总结时把提示过的思路记成你的独立发现。看到记录与实际不符时，直接告诉老师回读对话并修正即可。
