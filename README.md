# Notara · DSH 学习插件

把教材、笔记和讨论整理成可回看的知识库，再围绕学生的实际问题开展学习。课堂使用 DSH 原生会话，资料保存在本地 Markdown、PDF 与 Canvas 文件中。

## 可以做什么

- 整理资料，保留原文出处；以知识点、方法、前序依赖与具体例子组织图谱。
- 结合资料、学情和目标备课，使用阅读器、白板与图形辅助讲解。
- 记录实际的学习过程，把课后交付交给长期教师，安排下次可以继续的问题。
- 查看学习计划与到期问题；按需邀请同学讨论或进行不看解析的互讲。

这是 **DSH 插件版**，不是独立 Electron 桌面应用。共七个功能插件及一个 bundle；当前适配 DSH **0.2.1-rc.4**，需要 **Node.js 24+**。

## 从源码构建

```sh
npm ci
npm run build
npm test
```

`npm ci` 和构建会校验并应用本安装目录内的 DSH 宿主适配。请使用独立目录，不要共用正在运行的 DSH 安装。浏览器测试需要 Playwright Chromium：`npx playwright install chromium`。

生成本地插件安装包：

```sh
npm run pack:plugins -- release/0.1.2
```

然后按 [安装与升级说明](docs/RELEASE.md) 安装到独立 DSH profile。包名仍为 `@oh-my-student/*`；不要把已发布的旧版本当作这份源码的新构建。

## 代码入口

| 目录 | 内容 |
| --- | --- |
| `plugins/` | 教学预设、Vault、资料工作台、图谱、日历、计时器与 bundle |
| `prompts/` | 提示词与 Skill 的权威源；构建时同步到 presets |
| `templates/` | 文档模板与原创起始学习资料 |
| `showcase-examples/` | 合成学情与教学测试材料，不是真实学生档案 |
| `examples/lesson-preparation/physics/` | 原创物理备课样例 |
| `scripts/`、`tests/` | 构建、打包、宿主适配与回归检查 |

[来源与第三方说明](docs/PROVENANCE.md) 列出移植来源、字体和素材边界。旧开发仓库的历史设计稿与工作流快照没有作为当前使用说明导出。

## 数据与使用边界

学习资料以本地文件为准，SQLite 是可重建索引。使用远程模型时，实际读取的资料、图片与对话会发送给所选模型服务商；本地存储不等于完全离线。请自行配置模型账号，不要提交密钥或真实学生资料。

本仓库不分发商业教材、教材拆解学习集、真实课堂轨迹或个人画像。模型生成的教学内容及学习记录仍需核对。Windows 安装及跨平台完整课堂尚未完成实机验收。
