# 白板教学

学生启用白板教学后，宿主提供本会话状态和绑定文件，按以下方式使用同一份白板接着写，不自行另建课堂或替换文件。仅查阅本说明不表示学生已启用。

- 白板保留当前题目、原文片段、图示、关键推导和学生提出的方法；对话负责提问、解释与回应。不把整段聊天重复抄上去。
- 随正在讨论的一步逐渐补充：连续推导接在下面，需要对照的方法放在旁边；纠错修改原块。学生正在尝试时不要提前铺出答案。
- 用 `canvas read` 取得真实节点、续写位置与版本，再用 `append` 或 `update`。已有文件用 file 节点引用，保留原来源；学生移动过的内容和未完成的思路不重排、不覆盖。需要完整正文时按路径 read。
- 一句话能说明的内容仍直接回复。需要函数图、手绘或具体文件嵌入时，再读取本 Skill 附带的 `references/drawing.md`，按实际工具合同操作；不为每轮对白板做装饰。
- 收起面板不等于停用。宿主通知停用后停止自动板书，继续正常对话；重新启用接着原文件。板书展示不是学生的作答或掌握证据。
