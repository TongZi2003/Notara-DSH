# 矩阵链区间 DP

## 内容

### 原题

**原创示例。** 矩阵 $A_1,A_2,A_3$ 尺寸分别为 $10\times30,30\times5,5\times60$。按通常三重循环矩阵乘法，以标量乘法次数计成本，求最优括号化，并写推广到 $n$ 个相容矩阵的区间 DP。

## 参考理解

### 原解

结合律保证最终矩阵相同，计算代价却不同。$(A_1A_2)A_3$ 先花 $10\cdot30\cdot5=1500$，中间矩阵为 $10\times5$，再花 $10\cdot5\cdot60=3000$，共 $4500$。$A_1(A_2A_3)$ 则为 $30\cdot5\cdot60+10\cdot30\cdot60=27000$。

若 $A_i$ 尺寸为 $p_{i-1}\times p_i$，记 $M[i,j]$ 为乘 $A_i\cdots A_j$ 的最小成本。最后一次乘法必有分割点 $k$，所以

$$M[i,j]=\min_{i\le k<j}\{M[i,k]+M[k+1,j]+p_{i-1}p_kp_j\}.$$

边界 $M[i,i]=0$；按区间长度从短到长算，左右子区间都更短，先前已有值。记录最优 $k$ 后递归输出两边括号，不能只给成本却声称已经还原方案。

状态数 $O(n^2)$，每态枚举 $O(n)$ 个分割，时间 $O(n^3)$、表空间 $O(n^2)$。这是标准标量乘法模型，不是所有快速矩阵算法或硬件上的实际耗时保证。本题三矩阵直接枚举两种括号可独立核对 DP 的 $4500$。
