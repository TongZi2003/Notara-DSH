# LCS 与子序列

## 内容

### 原题

**原创示例。** 对字符串 $X=\text{ABCBDAB}$、$Y=\text{BDCABA}$，求最长公共子序列长度和一个方案。说明“子序列”与“连续子串”的区别，不把下标相邻当作必要条件。

## 参考理解

### 原解

令 $L[i,j]$ 表示 $X$ 前 $i$ 字符与 $Y$ 前 $j$ 字符的 LCS 长度。空前缀边界为零。若末字符相同，可在两边较短前缀的 LCS 后接这个字符，$L[i,j]=L[i-1,j-1]+1$；若不同，至少一边末字符不被共同匹配，故取 $\max(L[i-1,j],L[i,j-1])$。按行或按列递增，依赖均已计算。

末字符相同时，采用匹配末字符的最优方案总能达到最优长度；这一等式不是说每个最优方案都必须匹配这两个位置。填表得到 $L[7,6]=4$。从右下角倒走，匹配则取字符并对角移动，不同则沿保持最优长度的上/左格走，逆序收集后可得 `BCBA`；`BDAB` 也是合法最优方案。

`BCBA` 在两串中都按顺序出现，但位置无需连续。更小的对照是 `ABC` 与 `AC`：LCS 是 `AC`，长度 $2$；最长公共连续子串只有长度 $1$。时间 $O(|X||Y|)$、完整表空间同阶；滚动数组可省求值空间，但不能不加处理地用丢弃的格子回溯路径。

### 下次探讨

遇到上/左两格同值，任选其一会影响最优长度，还是只影响交付哪一个最优方案？
