# 来源与成本口径

本套解释和题面为模板编写，采用动态规划的标准模型，不摘录某平台题目、指定教材或论文，也不虚构题号、作者授权、页码或官方评分标准。“原创示例”指本次教学题面，不表示首次提出硬币、背包、LCS 或矩阵链这些经典问题。

状态、最优子结构、记忆化、DAG 最优路径、背包、LCS、矩阵链属于常用算法知识。本套用特定小输入推导与反例检查，不把小规模实算当作一般正确性证明。复杂度默认单位代价整数算术，并区分数值大小与输入位数；Fibonacci 明示大整数位数限制，容量/金额 DP 明示伪多项式口径。

硬币与背包默认金额/重量为正整数；DAG 不含环；LCS 的字符比较按常数时间；矩阵链采用普通标量乘法计数。学生理解、作答、代码提交、平台测试与复习记录均未填入。没有原书 PDF，未制造页图或来源附件。
