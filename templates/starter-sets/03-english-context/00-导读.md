# 完形微语境证据链与熟词僻义

先在三篇完整短文中看清“观察—限制—决定”的叙事线索，再缩到三句微语境，比较同一熟词在不同对象、动作和语块中的含义。所有材料为原创虚构，不冒充高考真题。每次选词都要指出原文证据，也说明不能推到哪里。

## 前置与阅读路线

需要基本句法、代词指代与常见连接词。生词可以查，但先保留完整三句或全文；不用一个中文释义替代候选比较。

本套共10张卡，建议顺序如下；可在真实断点处返回前置，不必一次读完。

## 节点一：从全文证据走到有范围的判断

核心问题：原文支持哪个选择，又不支持哪些延伸？先看完整叙事中的限制、行动与结果，再比较选项。

教学目标：指出支撑选择的具体语句、排除竞争解释的理由，以及不能从材料推出的部分。

- [ ] [[01-暂定结论的词义选择]]：从图书馆试行的好评与样本限制理解tentative。
- [ ] [[02-连接词与两种服务渠道]]：从速度改进与可访问性理解转折。
- [ ] [[03-推断的范围与因果边界]]：分清传感器观察、风险与尚未证明的效果。
- [ ] [[04-概念-证据范围与候选比较]]：形成客观线索、候选比较、结论边界的顺序。

## 节点二：同一个词为何在两段材料中不同

核心问题：同一个熟词在两段材料中为什么需要不同解释？两份微语境供我们比较对象、动作和搭配。

教学目标：读全必要语境，指出让候选含义发生变化的证据，不只给中文释义。

- [ ] [[05-address处理顾虑]]：在纸质时刻表情境中辨别address a concern。
- [ ] [[06-address向听众讲话]]：在舞台情境中比较address an audience。

### 本节足迹

## 节点三：把语块放回角色与前后状态

核心问题：角色与前后状态怎样限制语块的含义？有了词义比较的经验，再看交易、任务分配与变化，横向整理后仍需回到各篇原文。

教学目标：用对象和语块解释选择，比较不同用法的条件；不能连通的义项可以分开保留。

- [ ] [[07-charge收取费用]]：辨认交易角色、金额和收费条件。
- [ ] [[08-take-charge-of负责]]：用分配任务和检查进度辨认负责。
- [ ] [[09-give-way-to变化]]：按前后状态理解替代，保留测试边界。
- [ ] [[熟词僻义与语块]]：跨篇比较语块，再回完整文章核对范围。

## 可以马上做的第一步

先读05的完整三句，在候选中选一个词，并圈出“问题”与“应对动作”各一处。然后与06比较：同一个address，哪些原文使它换了意思？白板可记录选择与一句证据。

打开 [[白板/章节.canvas|章节白板]]。所有学生理解留白，白板没有预填作答；参考推导属于材料。只有自己的实际表达才值得写入理解，正式复习另经现有面板或课堂建议确认。
