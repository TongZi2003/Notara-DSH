# 内置标杆学习集

在 Notara 的添加学习集入口选择下列任一模板，即可创建独立学习集并打开导读。首次使用会自动以《自学自救与 Notara 破冰指南》准备默认学习集。学生在自己的副本中阅读和作答，安装包内的模板不随学习修改。

## 高中与学习方法

- [自学自救与 Notara 破冰指南](00-self-study-guide/00-导读.md)：从看懂与提取的区别，到先验底座、笔记五问与整卷四分流。
- [函数、导数与放缩](01-derivative-methods/00-导读.md)：从区间最值到隐零点、指对同构与切线放缩的边界。
- [离子平衡与分布系数](02-ion-equilibrium/00-导读.md)：从分布图到三大守恒，连接酸碱与配位平衡。
- [英语微语境与语块](03-english-context/00-导读.md)：用完整微语境中的客观线索辨析词义，并跨篇积累语块。

## 大学章节

每套大学章节含 10 张卡、连贯导读、集中来源说明与原生 `.canvas` 白板。

- [极限与连续](01-limits-continuity/00-导读.md)：从数列和函数极限，到等价替换、收敛证明与连续函数定理。
- [特征值与正定](02-eigenvalues-positive-definite/00-导读.md)：从特征空间，到对角化、二次型及正定条件。
- [定积分应用](03-integral-applications/00-导读.md)：从黎曼和，到面积、旋转体、弧长和质量/功的微元模型。
- [动态规划](04-dynamic-programming/00-导读.md)：从状态与依赖，到背包、LCS 和区间动态规划。

题目为原创教学示例；通用定义与定理不冒充原创发现。没有指定教材、PDF、考试出处或官方评分标准。各套的条件与取舍集中放在自己的来源说明页。参考理解是供学习的解释，不是学生作答；白板含提示，揭帧和阅读答案均不自动证明独立完成。默认不预填学情、成绩、复习历史或排期。
