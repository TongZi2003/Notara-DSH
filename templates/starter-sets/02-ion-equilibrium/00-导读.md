# 水溶液离子平衡、分布图与守恒

图上的三条曲线来自同一组平衡关系与总量归一化。先学会把交点译回公式，再加物料、电荷与质子条件，区分“外部设定 pH”与“投料后自行平衡 pH”；最后用 Lewis 电子对视角走到配位。

## 前置与阅读路线

需要浓度、化学平衡常数、酸碱解离、常用对数和基本代数。所有数值题采用明确的理想模型，方括号浓度按1 mol/L归一化；H₂A是形式酸，不代表实测化合物。

本套共10张卡，建议顺序如下；可在真实断点处返回前置，不必一次读完。

## 节点一：怎样从平衡关系读出组成

核心问题：图上的比例和“占优势”分别意味着什么？先从平衡关系计算，再检查直觉描述与实际比例的差距。

教学目标：写清比值与分数的对象及条件，用数值核对对组成的判断，不只凭曲线高低下结论。

- [ ] [[01-从平衡到分布系数]]：从两级平衡得比值，再得到分数。
- [ ] [[02-pH5到底有多少中间形态]]：以精确比例纠正“几乎全部”。
- [ ] [[03-优势形态与图像边界]]：比较占比最大、90%门槛及滴定图边界。
- [ ] [[04-概念-比值与归一化]]：收拢前面三题的共同步骤。

## 节点二：图上每一种信息对应什么关系

核心问题：交点、纵轴与趋势分别支持哪些化学判断？学会计算后再把图像译回关系，相似图形也需要先辨认对象。

教学目标：指出所用的图像证据及其对应关系，核对坐标和条件，不从一个交点外推全部组成。

- [ ] [[08-交点与对数比值读图]]：相邻/非相邻交点、纵轴和斜率分别辨认。

### 本节足迹

## 节点三：当 pH 是未知量时，还缺什么约束

核心问题：从给定 pH 读取组成，改为求投料后的 pH，还缺哪些关系？这里用守恒连接组成与实际未知量。

教学目标：列清物种、所守恒的量和未知量，检查近似适用条件；卡住时回到缺失的关系，不机械套公式。

- [ ] [[05-物料守恒与电荷守恒]]：列完整物种，按骨架与电荷分别计数。
- [ ] [[06-质子条件与参考形态]]：从前两式消元，理解参考形态。
- [ ] [[07-两性盐的pH不是外部旋钮]]：求NaHA自身平衡，检查常用近似的条件。

### 本节足迹

## 节点四：换一种酸碱视角能解释什么

核心问题：质子供受解释不了的问题，可以换什么视角看？最后比较不同视角的对象与用途，再整理选择关系的依据。

教学目标：在具体例子中说明所用视角与条件，保留各自边界，不把一种解释强套到所有问题。

- [ ] [[09-从Bronsted到Lewis配位]]：从质子供受拓展到电子对供受。
- [ ] [[守恒与酸碱视角]]：按题目实际未知量与物种选择关系。

## 可以马上做的第一步

先在01把三种含A形态的比写全，再到白板 figure 点选 H₂A 与 HA⁻ 的交点，用相邻解离关系说明横坐标。图像取点允许近似，精确比例回08核对。

打开 [[白板/章节.canvas|章节白板]]。所有学生理解留白，白板没有预填作答；参考推导属于材料。只有自己的实际表达才值得写入理解，正式复习另经现有面板或课堂建议确认。

已有 assets 分布图和交互 figure 来自同一套公式；不把受控pH分布图当滴定曲线，也不把盐溶液pH近似值当实验值。配位例题是概念比较，不提供真实化学实验操作。
