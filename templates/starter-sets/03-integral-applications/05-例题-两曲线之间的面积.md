# 两曲线之间的面积

## 内容

### 原题

**原创示例。** 求 $y=x$ 与 $y=x^2$ 围成区域的面积。再说明为何 $\int_0^{2\pi}\sin x\,dx$ 不等于正弦曲线与横轴之间的总面积。

## 参考理解

### 原解

先求边界交点：$x=x^2$ 给 $x=0,1$。在 $[0,1]$，$x-x^2=x(1-x)\ge0$，所以竖条的上边界为 $x$，下边界为 $x^2$，高度是二者之差。面积为

$$A=\int_0^1(x-x^2)dx=\left[\frac{x^2}2-\frac{x^3}3\right]_0^1=\frac16.$$

确定上下关系是建模步骤，不是积分之后再给负数取绝对值。若两曲线在区间内交换上下位置，应按交点分段或直接积分绝对差。

正弦在 $[0,\pi]$ 非负，在 $[\pi,2\pi]$ 非正；有向积分的两部分 $2$ 与 $-2$ 相抵，得到 $0$，但几何总面积是 $\int_0^{2\pi}|\sin x|dx=4$。一次给最终积分取绝对值，仍会错得 $0$。
