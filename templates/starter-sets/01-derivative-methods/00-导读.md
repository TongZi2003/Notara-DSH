# 函数性质、导数隐零点与放缩同构

先把定义域、单调分支和端点管住，再学三条结构路线：设而不求的隐零点、指对两边的同构、带条件的切线放缩。母题教你怎样起步，反例说明何时必须停下检查。各题原题与原解都完整保留，不把图上看起来正确代替证明。

## 前置与阅读路线

需要指数对数的定义域与运算、基本求导、连续函数零点判断。02会用正半轴两端的函数趋势；第一次不熟悉时可先读04的分支说明，再回题面。

本套共10张卡，建议顺序如下；可在真实断点处返回前置，不必一次读完。

## 节点一：驻点之外还要检查什么

核心问题：求出导数后，区间还怎样限制最值与根数？这一站先用概念说明判断对象，再在三道题中核查。

教学目标：能说明定义域、单调分支与边界各自参与哪一步，并比较区间变化带来的限制；先尝试，再展开参考理解。

- [ ] [[04-概念-单调分支与边界]]：先验底座：定义域、单调性、边界分别管什么。
- [ ] [[01-变化区间上的最值]]：在变化区间中比较驻点与端点。
- [ ] [[02-水平线与两个根]]：用分支值域判断交点。
- [ ] [[03-有限区间的根数比较]]：把同一判断放到有限开闭区间。

### 本节足迹

## 节点二：求不出根，还能推进哪一步

核心问题：难以显式求根时，哪些关系仍能推动求解？反例再提醒我们检查所求量与结论范围。

教学目标：说明隐零点推导中每一步的依据，再检查结论适用的范围，不把局部结果直接当作全局结论。

- [ ] [[05-母题-隐零点与高次代换]]：用唯一根满足的关系降幂，不急于求根式。
- [ ] [[06-反例-驻点不等于全局最值]]：检查定义域和全局行为。

### 本节足迹

## 节点三：同样的形式能推出同样的输入吗

核心问题：两个表达式写得相似，凭什么能继续推出结论？先检查连接它们的函数满足哪些条件，再比较母题和反例。

教学目标：在实际取值范围内检查推导前提，并指出两题开始需要不同判断的位置。

- [ ] [[07-母题-指对同构与单调性]]：换元后识别同一个单射函数。
- [ ] [[08-反例-同构函数不一定单射]]：同形还不够，要核对单调分支。

### 本节足迹

## 节点四：选择结构路线，核对放缩方向

核心问题：面对新题，怎样选择路线并核对放缩条件？前面的方法各有用途，不要求所有题归于同一技巧。

教学目标：在具体题中说明所选路线的依据，并检查放缩方向、适用区间与取等条件。

- [ ] [[09-切线放缩与失效边界]]：证明单侧界，检查组合方向与等号。
- [ ] [[函数结构]]：将三条路线与反例组织成可回访的中枢。
