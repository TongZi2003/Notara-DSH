# 使用指南：用原创样例走完提问、学习、记录和续接

完成 **[安装指南](INSTALL.md)**、配好模型并选中你的学习工作区后，我们就可以开始第一堂课了。

在 Notara 里，你不需要先把整本教材导进去，也不需要像闯关打卡一样把所有功能全用一遍：
- **平时随手用**：遇到一道卡住的题、一段没看懂的推导，或者想整理一页课堂笔记，直接打开对话框按需讨论、随时记录。
- **集中攻坚用**：遇到一个总是绕不明白的专题，或者周末有一整块时间想系统梳理一章内容，就让首页助手帮你备一节课、开一门新课，把硬骨头彻底啃下来。

不管走哪条路，核心都只有一件事：**把今天真正想通的地方留下来，并明确下一次从哪个具体问题接着往下走。**

---

## 一、15 分钟跑通一次完整学习闭环

下面我们用仓库自带的原创导数起始材料（如果安装时跳过了复制，可以按 **[安装指南第 3 步](INSTALL.md#3-配置插件和资料目录)** 把 `01-derivative-methods` 复制进你的资料目录，也可以直接换成你手头的一道真题）走完一遍「提问 → 课堂学习 → 记录沉淀 → 下次续接」。

### 1. 向「首页学习助手」说明起点与目标，开启专题课堂

新建一段会话，在输入框下方的角色菜单中选择 **「首页学习助手」**，用自然语言告诉它你手头的材料、现在的水平和今天的时间：

> 我会基本的求导计算，但一遇到区间或函数里带参数，分类讨论就容易漏情况。今天我有 30 分钟，想结合资料库里的《01-变化区间上的最值》弄明白：为什么算出导数等于 0 的驻点之后，还要去和区间端点反复比较？请先看一眼这份资料，帮我安排一小节课。遇到卡点时先给我搭一步台阶，让我自己往下算。

这句话自然地交代了 **A 手头资料 + B 自身起点 + C 今日目标与时间**。如果不确定自己到底卡在哪里，也可以直说「这道题我算完导数就不知道下一步该干嘛了」，让老师一步步问清楚。

「首页学习助手」读取资料后，会为你建立或更新学习画像、规划本节重点，并创建一个独立的专题课堂。当对话框里出现课堂入口卡片时，点击 **「打开专题对话」**，就会跳转到专门负责本节课的 **「专题课堂老师」** 会话。

> **小贴士**：这段「首页学习助手」会话就是你的长期主线入口，平时保留它即可；每门具体课程在各自的专题对话里展开，互不干扰。

### 2. 在专题课堂里学习：先动笔尝试，再顺着台阶往上走

进入专题课堂后，点击左侧导航栏的 **「资料」**，打开 `01-变化区间上的最值.md`。先看题面，暂不展开下方的「参考理解」。

如果老师在课前为你准备了一份备课本（`type: lesson`），你可以在会话右上角点击 **「活动」→「关联备课本」** 绑定这份课稿，展开 **「本课清单」** 随时对照本节课的推进步骤。

准备好后，在对话框里发出你的第一步尝试：

> 我先看完了题面。求导之后是 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，驻点是 $x = -1$ 和 $x = 1$。但接下来区间是 $[a, a+2]$，我一看到参数 $a$ 在动，脑子里就乱了，不知道该按什么标准分段。如果参数太抽象，能不能先带我拿一个具体区间试试？

在接下来的对话里，不用急着一口气交出完美答案：
- **把真实的草稿步骤发出去**：哪怕只写出了一半、或者算错了符号，发给老师看也远比只回一句「看懂了」更有用。
- **诚实标记谁想到了哪一步**：如果某一步变形是老师提示后你才接上的，直接说「这一步是你提醒我先画增减区间我才反应过来的，刚才我自己没往这想」。
- **需要画图或检验时再调出工具**：想直观看到区间滑动时最值怎么跳变，可以让老师直接在对话里画出函数与动态区间图；想自己从头顺一遍逻辑，可以点输入框的 **「请同学」→「讲给同学听（不看解析）」→「大肥鱼」**，把你的理解讲给不知道答案的虚拟同桌听，看看能不能应付它的追问。

### 3. 课后收尾：沉淀真实理解，留下一个「下次继续的问题」

当这节课的核心卡点已经想通、或者今天的时间差不多了，直接告诉专题课堂老师收尾：

> 今天先学到这里吧。请帮我把这节课真正自己算出来的步骤、以及你提示我的关键分界点记进卡片的「学生理解」里，把还没彻底练熟的地方留成一条「下次可以继续探讨的问题」，并把本节课的总结交回给首页学习助手。

老师完成写入后，会把更新过的卡片和报告链接发给你。点开 `01-变化区间上的最值.md`，你会看到三处实质性的变化：
1. **「学生理解」记录了真实的认知过程**：清楚区分了「能独立求导定驻点」和「在提示下通过画定轴动区间图理解了分界点 $a=-1, 0, 1$ 的由来」。
2. **知识图谱点亮了对应的实线**：由于你在这道题上真正走通了 `[[04-概念-单调分支与边界]]` 的应用，打开左侧 **「知识图谱」** 时，原本代表「待建立联系」的虚线已经变成了代表「已建立真实理解」的实线。
3. **留下了可演进的后续问题**：卡片里不再是空洞的「继续巩固导数」，而是具体的问题——例如 *「如果函数本身带参数而区间固定，分界点又该拿谁和谁比？」*，并根据你今天靠提示完成的实际情况，自动安排了短周期的回访时间。

> **随时纠偏**：如果点开卡片发现老师把「它提示你的步骤」误写成了「你独立想出的步骤」，直接在对话里说：*「刚才拿端点和极值点直接比大小是你先提醒我的，我只是顺着算出了分界值，请把这两步的归属分开记。」* 老师会立即回读并修正文件。

### 4. 下次续接：顺着上次的问题往前走

第二天或几天后重新打开 Notara 时，你有三种最自然的续接方式：

1. **直接找「首页学习助手」**：
   回到那段长期主线对话，问一句：*「看看上次导数课的交付记录，我今天晚自习后只有 15 分钟，接着看哪个问题最合适？」*
2. **从「待复习」队列切入**：
   点击左侧 **「资料库总览」**，在右上角视图菜单中切换到 **「待复习」**。这里会按到期顺序列出每张卡片留下的具体后续问题，点击即可将该问题与卡片引用一并带入输入框草稿。
3. **从「学习日历」切入**：
   打开左侧 **「学习日历」**，当天的待办里会同时显示「学习计划排程」和「到期回访卡片」。点击卡片旁的 **「继续讨论」**，同样会把上次留下的追问带入对话框，由你确认后发送。

到这里，你就完整跑通了一次 **「带着问题进场 → 搭台阶想通 → 沉淀真实记录与图谱 → 到期带着新问题回访」** 的闭环。

## 二、日常学习的三种常见打开方式

除了上面这样的专题小课，平时遇到不同体量的学习任务，可以按需选择最顺手的方式：

### 1. 随手记笔记、问单题（最轻量的日常用法）

平时做作业遇到一道卡壳的题，或者刚听完学校的课想整理一页笔记，完全不需要先建路线或备课：
- 直接在会话里把题目、草稿或疑问发出去，比如：*「我只想快点弄明白为什么导数等于 0 不一定是极值点？拿一个最简单的反例给我看一眼就行，不用开整节课。」*
- 讨论清楚后，如果觉得这个反例或规律值得留下来，说一声 *「帮我把刚才聊明白的这个反例记到对应卡片里」* 即可。

新建空白会话时，输入框上方还提供了四个常用场景胶囊，点击后会帮你铺好提问框架，你只需补上自己的材料就能发送：

| 快捷场景胶囊 | 适合什么时候用 | 建议一起发给老师的背景 |
| --- | --- | --- |
| **试卷诊断与补强** | 考完试或做完套卷，想从错题里揪出最核心的两三个漏洞 | 题目、批改结果、你当时的草稿步骤，以及考场上卡住时的真实想法 |
| **笔记整理与拓展** | 把学校的课堂板书、手写笔记或零散总结收进自己的知识地图 | 原始笔记文件或照片、你想重点保留的推导，以及没听懂想拓展的地方 |
| **考前复习与状态准备** | 距离月考/期中只剩几天，时间有限，想抓大放小稳住节奏 | 考试范围、剩余可用时间、近期常错的薄弱点 |
| **题库提高练习** | 学完一个模块，想挑几道有递进关系的题练手或做变式迁移 | 已导入的题库或讲义、想重点突破的方法、今天能投入的时间 |

### 2. 导入讲义或框选 PDF：把厚材料拆成知识骨架

当你拿到一份新讲义、一章教材 PDF 或一套试卷，想先把它们变成资料库里的结构化卡片时：

- **整份资料交由助手整理**：
  点击会话右上角 **「活动」→「添加来源」→「上传文件」**（或使用输入框附件按钮），选好文件后附上你的范围要求发送：
  > 这份是这周发的函数讲义。请先保留原件和出处，帮我拆出里面的核心概念、常用方法和代表性例题，并与我资料库里已有的卡片对齐。今天只做资料整理，先不开课，整理完给我一份清单。
- **在 PDF 阅读器里哪里不会框哪里**：
  在左侧「资料」中直接打开 PDF 文件，按住鼠标拖拽框选某道题或某张配图，顶部工具栏右侧会出现三个零拷贝操作：
  - **「带入选区」**：把当前框选的页码与区域引用直接塞进对话草稿，马上针对这一小块提问。
  - **「基于选区创建卡片」**：输入标题即可生成一张带精确页码与区域坐标引用（`page + rect`）的卡片，点击卡片上的 **「查看原页」** 随时跳回 PDF 原位置，不产生冗余截图文件。
  - **「PDF 选项」→「请老师生成卡片」**：将选区连同整理要求一起填入草稿，交给老师提取题面并挂接到对应知识点。

### 3. 启用白板、共绘与同桌讨论

当纯文字对话不够用时，可以在课堂里随时叫出辅助工具：

- **课堂白板（`.canvas`）与同屏共绘（`.excalidraw`）**：
  在老师输入框中输入 **`/`**，选择 **「启用白板教学」**，即可在右侧打开并绑定当前课堂的 `.canvas` 白板，适合把原题、分步推导、多解对比和函数图并排铺开；需要手绘受力分析、几何辅助线或单调区间表时，老师或你都可以在关联的 `.excalidraw` 画板上直接动笔共绘。用完后输入 `/` 选择 **「停用白板教学」** 即可收起，白板文件会完整保存在资料库中。
- **邀请四位虚拟同桌（`请同学`）**：
  在「专题课堂老师」输入框下方点击 **「请同学」**，可以根据当前需要召唤不同性格的伙伴：
  - **讲给同学听（不看解析）**：例如叫出基础偏弱但爱追问直觉的**「大肥鱼」**。系统会自动屏蔽之前的课堂上下文与标准答案，只把你写的原题和讲解发给它，逼着你用不跳步的语言把道理讲通。
  - **课堂伴学讨论**：叫出擅长归纳结构的**「小李」**、喜欢抠边界反例的**「阿哲」**，或是注重考场心态与防坑节奏的**「林晓」**，从不同视角陪你碰撞思路。

## 三、看懂你的四大工作台视图

左侧导航栏的四个面板，分别从不同维度展示同一份本地 Markdown 资料库：

1. **资料库总览**：
   默认按「原始来源」聚合展示你导入的讲义、笔记和试卷，点击任一来源即可查看从它拆解出来的所有概念、方法与例题卡；也可以通过右上角切换为「全部资料」或「待复习」列表，并按卡片类型、来源、标签快速筛选。
2. **知识图谱**：
   直观呈现你的知识地图。通过右上角齿轮可以在「按来源聚合」、「按知识点聚合」与「以资料为中心」之间切换。图谱上，**概念与方法**构成前序依赖主干，**例题与实验**挂接在四周；**虚线**代表资料里存在但你还没亲自走通的联系，**实线**则代表你已经在某次推导或练习中真正建立起联系的足迹。
3. **学习计划**：
   按阶段展示你的长期学习路线图（`type: plan`）、里程碑状态、关联卡片以及每次课后自动汇入的进度修订记录。
4. **学习日历**：
   把「定了具体日期的计划任务」和「到达动态复习窗口的卡片问题」汇总到每一天。如果某天作业太多没来得及看，到期卡片会保留在待办里，你也可以点击条目右侧的 `⋯` 随时改期。每天的课堂交付索引会自动记入 `日记/YYYY-MM-DD.md`，顺着日记里的链接就能随时回看任意一节课的完整总结。

## 四、所有资料始终归你所有

你在 Notara 里积累的每一张知识卡片、个人画像、学习路线、每日记录与白板，全部是保存在本地工作区目录里的标准 Markdown（`.md`）、JSON Canvas（`.canvas`）和 Excalidraw 文件。即便脱离本软件，你依然可以用 Obsidian 或任何文本编辑器直接打开、搜索和编辑它们。
