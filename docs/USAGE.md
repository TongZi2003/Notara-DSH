# 第一次学习与日常用法

先完成 [安装与启动](INSTALL.md)，配置一个可用模型，并选中自己的学习工作区。

Notara 不要求先把整本书导进来。你可以带着一个问题直接聊；有整块时间时，再走「整理 → 备课 → 课堂」的路线。两条路都围绕同一件事：**这次真正想通了什么，下次从哪里继续。**

## 先跑通一个小闭环

下面使用仓库里的原创导数起始章节。如果安装时没有复制，现在可按 [安装文档第 3 步](INSTALL.md#3-配置插件和资料目录)复制，或换成自己的题目。示例中的学情只是写法示范，请改成自己的真实情况。

### 1. 告诉长期教师，你现在需要什么

新建一段会话，选择**「首页学习助手」**，比如这样说：

> 我会基本求导，但遇到区间带参数就容易分类混乱。今天有 30 分钟，想用《变化区间上的最值》弄清楚：为什么求出驻点后，还要比较端点？请先读资料，帮我安排一小节课。不要默认我已经会参数分类，卡住时先给一步提示。

这句话给出了 **A 资料、B 起点、C 目标与时间**。不必写专业提示词；不确定自己卡在哪，也可以说「我只知道这一段看不懂」，让老师逐步问清楚。

学习助手可以据此建立画像、安排下一步，并创建专题课堂。收到课堂入口后点**「打开专题对话」**，进入实际授课的会话。以后保留这段学习助手对话作为长期接续入口，不必每次重新建一位老师。

### 2. 看资料，再开始尝试

从左侧**「资料」**打开 `01-变化区间上的最值.md`。先只读题面，不急着展开「参考理解」。

如果老师先生成了备课本，可以打开它看本课任务；详细解答放在折叠的「教师参考」中。老师会话右上角**「活动」→「关联备课本」**可以选中这份课稿，展开**「本课清单」**查看进度。

然后明确开始：

> 开始吧。先让我写导数和定义域，再看我卡在哪里；如果参数太抽象，先拿一个具体区间看。

不必追求一次做完原题。把自己的实际步骤发出去，比只说「懂了」更能帮助老师接上下一步。老师已经写出的式子，也可以直接说「这一步是你给的，我还没自己想到」。

### 3. 收尾时保存事实，留下一个问题

准备结束时，直接说：

> 今天先到这里。请保存我真正做出的步骤和你给过的关键提示，把还没弄清的地方记成「下次可以继续」的问题；如果适合回访，再安排时间。把本节总结交回学习助手，并给我实际保存的文件链接。

保存后点开链接，看三件事：这次谁做了哪一步、哪里仍然不清楚、下次的问题是否具体。比如「换一个区间后，先判断驻点在不在里面」比「继续巩固导数」更容易开始。

如果记录写偏了，可以直接纠正：

> 不等式是你先给出的，我只是在提示后补了取等条件。请把这两步分开记，不要写成我独立完成全过程。

专题课堂的总结会通过现有交付机制交给绑定的长期教师；完整报告留在相应文档里，日记保留交付索引。如果还没有绑定的学习助手，就先保留报告，不要把“已保存”误当作“另一位老师已收到”。

### 4. 下次接着问

回到原来的**「首页学习助手」**会话：

> 看看上次课堂的交付，今天只有 10 分钟，从哪个问题继续最合适？

也可以从**「资料库总览」→视图菜单→「待复习」**找到具体问题，点击后带入长期教师的输入草稿，再由你发送。日历中的卡片到期问题也可点**「继续讨论」**；都不会替你自动发送消息。

至此就跑通了一次「资料 → 讨论或课堂 → 保存 → 续接」。不用等图谱变得很大，第一张卡片就可以开始。

## 有一批材料时：先整理，再决定要不要备课

### 把资料交给助手

在会话右上角打开**「活动」→「添加来源」→「上传文件」→「选择文件」**；也可以使用输入框的附件入口。选好文件只是加入草稿，补上要求后再发送：

> 这份是学校的笔记。先保留原件和出处，整理其中的概念、方法和具体例子，与已有卡片对齐。对我自己写的想法和老师的板书分别记录。今天只整理，先不上课，最后给我整理清单。

发送的文档附件会导入当前工作区的 `来源/`。**导入不等于已经阅读或整理**；单纯往工作区复制文件，也不会自动启动一轮资料整理。

在**「资料库总览」**默认先看原始资料。点击来源标题可进入相关卡片，**「打开原文」**回到资料本身；也可以切换「全部资料」并按类型、来源、标签筛选。

### 从 PDF 的一小块开始

打开 PDF，拖拽框选题目或图形，然后使用顶部工具栏右侧的操作：

- **「带入选区」**：放进当前对话草稿，补上问题后发送。
- **「基于选区创建卡片」**：填写标题并创建，保留原页与区域引用；不是自动生成完整解答。
- **「PDF 选项」→「请老师生成卡片」**：先填好整理请求，再交给老师处理。

卡片中的**「查看原页」**可回看出处。原 PDF 仍要保留在学习集内，否则引用无法凭空恢复。

### 需要系统学，再准备一节课

> 从刚整理的资料里选一组有递进关系的例子。结合我的画像，准备一节 40 分钟的课：先让我看见现象，再跨过最关键的思维障碍；保留卡住时可以退回的具体台阶。先备课，暂不开始授课。

主老师负责整课取舍与统稿，按任务依赖请调研员补材料，再由审核员审最终稿；不是先让几位工作员各写一段后拼成课。备课完成后，打开课稿、关联清单，再明确说「开始上课」。

## 只是一个临时疑问时，直接聊

不必先整理、建路线或备课：

> 我只想搞清楚：为什么导数等于零不一定有极值？先用一个简单反例解释，不用安排整节课。

你也可以临时探索新条件、比较两种方法，或回头查以前相关的卡片。普通探索有认识变化就可以记录，不必每次都证明“独立掌握”，也不必每次都排期。

空白会话的四个场景入口，分别适合这些情况；点选后仍可改草稿、补材料再发送：

| 入口 | 最值得带来的背景 |
| --- | --- |
| 试卷诊断与补强 | 题目、批改、自己的作答和草稿；尽量回忆当时怎样想。没有作答就先讨论，不编造错因。 |
| 笔记整理与拓展 | 原笔记、想保留的内容，以及想比较或拓展的方向。 |
| 考前复习与状态准备 | 考试范围、剩余时间、已有弱点与近期状态；时间不足就缩小目标。 |
| 题库提高练习 | 可用题库、想练的能力和时间；让老师说明选题之间的递进，而不只是堆题。 |

## 工具在需要时出场

### 白板与共绘

在老师输入框输入 **`/`**，选择**「启用白板教学」**，会绑定并打开课堂白板；再选**「停用白板教学」**可以停止使用，文件内容仍保留。当前状态可从白板菜单查看。

白板适合长推导、并排对照、文件嵌入与图形；共绘使用 `.excalidraw`。简单函数图也可以直接出现在对话中，不必为了画一条曲线先启用整张白板。启用白板本身不等于老师已经开始写板书。

### 请同学听自己讲

在**「专题课堂老师」**输入框点**「请同学」**。想练习讲清楚，可以选**「讲给同学听（不看解析）」→「大肥鱼」**，提供原题与自己的讲解后发送；同学会话可在**「活动」→「子智能体」**中打开。

这个入口不把此前完整课堂和解析交给听讲同学，让它顺着你的表述追问，类似找一只会说话的橡皮鸭。你主动提供的内容仍会影响它，所以不要把答案也夹进原题里。其他同学可用于回答或自由讨论，但同学的回答不是你的作答证据。

## 地图、计划和记录分别看什么

- **知识图谱**：默认按来源聚合；通过齿轮切换知识点聚合或以资料为中心等视图。概念与方法是主干，题目、实验、事件分析等是具体例子。一条来源线只说明出处；知识联系的实线表示已有建立记录，也可能是在提示后形成的，不等于从此不会遗忘。
- **学习计划与日历**：给计划条目安排日期，才会进入相应日期的待办；到期卡片的问题是另一类待办。普通 Markdown 勾选框不会全塞进去。未处理的到期事项保留，日期不合适可在 `⋯` 中改期。
- **卡片与日记**：卡片保留局部认识和问题，日记串起每天工作交付。查看课后报告时，从「资料」打开 `日记/` 下的当天文件，顺着交付索引回到报告；不必依赖日历能展示所有报告。

长期教师根据这些记录调整方向，不需要重新灌入每堂课的全部细节。画像不是成绩单：稳定偏好可以保留，推测要澄清，老师给的帮助与错误也应如实分开。

## 学完后，这些东西仍归你

卡片、画像、计划、日记和白板都在自己的资料目录里，可以用 Obsidian 或文本编辑器继续打开。课堂消息则保存在 DSH 环境中，所以迁移和备份时要同时保留资料目录与 DSH_HOME。

远程模型会收到本次实际发送或读取的内容。涉及学生隐私时，先决定哪些材料适合交给服务商；不要把本地文件保存误解为全程离线。模型也会犯错，尤其需要核对题设条件与学习记录的动作归属。
